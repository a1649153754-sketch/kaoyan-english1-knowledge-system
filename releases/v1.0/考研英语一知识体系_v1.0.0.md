# 考研英语一知识体系 v1.0.0

> 一套面向**考研英语（一）**的可持续知识库：以固定节点、规则卡、母题、反例和个人真题证据组织复习。

## 0.1 项目边界

- 默认科目：**201 英语（一）**。
- 本项目按近年来稳定题型组织，报考年度的题型、分值和要求以教育部教育考试院当年发布的大纲为准。
- 不收录未经授权的整套真题、文章或教材原文；只记录年份、题号、考点、证据摘要和原创例句。
- 英语（二）可在后续版本建立独立分支，避免混用写作与翻译要求。

## 0.7 使用闭环

1. 学一个节点，只记录概念、触发信号、主方法、边界和达标证据。
2. 做题后挂到 `Q` 母题与节点编号。
3. 错题贴 `LEX/SYN/LOG/EVI/INF/TIME/EXP/FMT` 标签。
4. 生成一句迁移规则，安排 3/7/14 天复测。
5. 每周只主攻 3—5 个 A+/A 节点，依据证据升降级。

# V · 词汇与语义

> 把单词从“中文释义表”升级为可在语境中识别词义、搭配、语气和句法位置的网络。

默认优先级：**A+**。优先级会随个人真题数据调整。

## 模块节点总览

| 节点 | 主题 | 学习目标 | 达标证据 |
| --- | --- | --- | --- |
| V1 | 语境词义与一词多义 | 根据上下文、搭配和论证方向确定词在当前句中的可译义，而不是背诵唯一中文释义。 | 能在 20 秒内说明“词性—搭配—语境—最终义”四步证据。 |
| V2 | 构词法与词形判断 | 利用词根、前后缀和词形变化推断词性、方向和大致语义。 | 能拆解常见前后缀并说出其“方向作用”，而非死背中文。 |
| V3 | 搭配、短语与介词系统 | 把动词—名词、形容词—介词、名词—介词和短语动词作为整体调用。 | 能为高频核心词建立至少 3 个真实搭配，并能在句中正确变形。 |
| V4 | 同义词、反义词与语气强度 | 区分近义词在范围、程度、立场、语域和搭配上的细微差别。 | 能用一句话说清两个近义词的最小差异，并各给一个自然搭配。 |
| V5 | 词汇记忆与复习闭环 | 通过真题语境、主动提取和间隔复习形成长期可调用词汇。 | 核心词在三次跨语境回测中均能正确识别，重要词块能主动造句。 |

## V1 语境词义与一词多义

根据上下文、搭配和论证方向确定词在当前句中的可译义，而不是背诵唯一中文释义。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 选项均认识却难以取舍；熟词放入句中不通；同一词在不同文章中译法变化。 |
| 主方法 | 先定词性与句法角色，再看左右搭配、段落主题和褒贬方向，最后选择最小充分释义。 |
| 替代/验证路线 | 把候选义分别代回原句，比较哪一个最符合主谓宾关系和上下文逻辑。 |
| 复核标准 | 替换后句意、语气和论证方向同时成立，且不额外添加原文没有的信息。 |
| 易错边界 | 词典首义不等于语境义；中文近义不等于英文可互换；不要脱离句子单独拍脑袋。 |
| 典型任务 | 熟词生义、词义猜测、完形近义词、翻译词义选择。 |
| 达标标准 | 能在 20 秒内说明“词性—搭配—语境—最终义”四步证据。 |

### 本节点七项检查

- [ ] 能区分词典核心义、常见引申义和本句语境义。
- [ ] 能通过主语、宾语和介词搭配排除不合句法的释义。
- [ ] 能利用段落主题判断词义的褒义、贬义或中性方向。
- [ ] 遇到熟词生义时先回到句法位置，不被最熟悉的中文义锁死。
- [ ] 能比较两个中文近义选项在英文搭配和语气上的差别。
- [ ] 词汇笔记同时记录原句、词性、搭配和语境义。
- [ ] 七天后只看原句仍能还原该词在文中的意义。

## V2 构词法与词形判断

利用词根、前后缀和词形变化推断词性、方向和大致语义。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 遇到生词但能辨认词根；选项词根相同而词性不同；句中需要名词、动词、形容词或副词。 |
| 主方法 | 先判断空位所需词性，再拆前缀—词根—后缀，最后结合语境校正。 |
| 替代/验证路线 | 若构词信息不足，退回同位结构、并列结构和搭配限制进行判断。 |
| 复核标准 | 词形必须同时满足句法位置、语义方向和固定搭配。 |
| 易错边界 | 构词法只能给出范围，不能替代上下文；相同后缀并不保证词性或含义完全一致。 |
| 典型任务 | 完形词形选择、生词猜义、阅读长词拆解、写作词性纠错。 |
| 达标标准 | 能拆解常见前后缀并说出其“方向作用”，而非死背中文。 |

### 本节点七项检查

- [ ] 能从冠词、介词、系动词和修饰关系判断空位所需词性。
- [ ] 掌握常见否定、反向、程度、时间和数量前缀的方向作用。
- [ ] 掌握常见名词、动词、形容词、副词后缀及常见例外。
- [ ] 能识别词根相同但词性、及物性或褒贬方向不同的词。
- [ ] 遇到长词能先保留词根核心，再结合句法推断。
- [ ] 能用词族表整理 noun/verb/adj/adv，而不是只记一个词形。
- [ ] 写作复核时能发现形容词副词、单复数和派生词错误。

## V3 搭配、短语与介词系统

把动词—名词、形容词—介词、名词—介词和短语动词作为整体调用。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 单词单看都通顺，但只有一个符合固定或高频搭配；介词选项难以区分。 |
| 主方法 | 先找搭配中心词，再检查其常见宾语、介词和语域，最后看语义是否贴合。 |
| 替代/验证路线 | 将表达改写成更熟悉的同义结构，验证介词关系和动作方向。 |
| 复核标准 | 搭配成立、语义自然、语域合适，三者缺一不可。 |
| 易错边界 | 不要把中文介词逐字映射到英文；短语动词意义常不能由单个小词机械相加。 |
| 典型任务 | 完形搭配题、阅读固定表达、翻译短语、写作表达升级。 |
| 达标标准 | 能为高频核心词建立至少 3 个真实搭配，并能在句中正确变形。 |

### 本节点七项检查

- [ ] 能识别动词与宾语之间的选择限制。
- [ ] 能识别形容词、名词后常接的介词结构。
- [ ] 能区分形式相近但方向不同的短语动词。
- [ ] 搭配笔记以词块为单位，不以孤立单词为单位。
- [ ] 能判断搭配属于书面、口语、正式或中性语域。
- [ ] 写作时优先使用确定无误的高频搭配，避免生造。
- [ ] 复盘时能说明错误是词义错、介词错还是搭配对象错。

## V4 同义词、反义词与语气强度

区分近义词在范围、程度、立场、语域和搭配上的细微差别。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 四个选项中文都可译成相似词；阅读选项通过换词改写原文；写作需要避免重复。 |
| 主方法 | 比较五个维度：对象范围、程度强弱、褒贬态度、典型搭配、正式程度。 |
| 替代/验证路线 | 寻找原文中的程度副词、限定词和评价词，作为强度与立场标尺。 |
| 复核标准 | 同义替换必须保持命题范围和态度强度，不可只看中文大意。 |
| 易错边界 | “意思差不多”不是可互换；强词替弱词、全称替部分都可能制造错误选项。 |
| 典型任务 | 阅读同义改写、态度题、完形近义辨析、写作替换。 |
| 达标标准 | 能用一句话说清两个近义词的最小差异，并各给一个自然搭配。 |

### 本节点七项检查

- [ ] 能区分程度强弱，如倾向、可能、必然等不同力度。
- [ ] 能区分事实描述词与带评价色彩的词。
- [ ] 能识别选项将部分范围扩大为全部范围。
- [ ] 能识别同义改写中的词性转换和上下义替换。
- [ ] 写作替换前先检查语域和搭配，而不是盲目追求高级词。
- [ ] 建立正向、负向、中性评价词组，而不是只背中文。
- [ ] 能通过原文限定词校准选项语气强度。

## V5 词汇记忆与复习闭环

通过真题语境、主动提取和间隔复习形成长期可调用词汇。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 背过多次仍认不出；阅读中认识但写不出；同一词反复错。 |
| 主方法 | 采用“原句识别—遮义回忆—词块输出—3/7/14 天回测”的闭环。 |
| 替代/验证路线 | 按词族、主题、同义改写或错误来源建立多入口索引。 |
| 复核标准 | 能在不同句子中识别并输出，而不仅能看到单词卡想起中文。 |
| 易错边界 | 不要无限抄词典；不要把低频生词和高频核心词投入同等时间。 |
| 典型任务 | 真题词表、写作词块、反复错词、熟词生义。 |
| 达标标准 | 核心词在三次跨语境回测中均能正确识别，重要词块能主动造句。 |

### 本节点七项检查

- [ ] 词汇按真题来源、主题和错误次数标记优先级。
- [ ] 每张词卡只保留与当前语境相关的必要信息。
- [ ] 完成当天、3 天、7 天、14 天主动提取。
- [ ] 能从中文功能或英文语境双向调用重要词块。
- [ ] 对反复错误词建立“混淆对象—最小差异”记录。
- [ ] 每周淘汰已稳定掌握的卡片，避免复习队列无限膨胀。
- [ ] 每月用新文章抽查词汇迁移，而非只复习旧卡。

# G · 语法与长难句

> 把语法从规则记忆转化为主干定位、修饰边界、逻辑关系和翻译重组能力。

默认优先级：**A+**。优先级会随个人真题数据调整。

## 模块节点总览

| 节点 | 主题 | 学习目标 | 达标证据 |
| --- | --- | --- | --- |
| G1 | 基本句型与主干定位 | 识别句子的核心谓语、主语、宾语或表语，建立所有长难句分析的骨架。 | 能在 15 秒内标出主句 S-V-O/C，并说明其余成分附着位置。 |
| G2 | 三大从句与关系词 | 判断名词性、定语和状语从句的功能、边界及关系词在从句中的成分。 | 能解释 that 与 when/where/which 的选择依据，而非凭中文感觉。 |
| G3 | 非谓语与压缩结构 | 识别不定式、动名词、现在分词和过去分词的逻辑主语、时间和语态关系。 | 能把常见非谓语结构双向改写为从句，并保持逻辑关系。 |
| G4 | 特殊结构：倒装、强调、省略与比较 | 识别因语序变化或成分省略造成的表面陌生结构，恢复正常语序和完整信息。 | 能在不依赖术语的情况下把特殊结构还原并准确解释。 |
| G5 | 长难句综合切分与指代 | 整合主干、从句、非谓语、插入语和指代，形成可复核的句义。 | 能画出句子层级并在 60 秒内给出准确、自然的中文释义。 |

## G1 基本句型与主干定位

识别句子的核心谓语、主语、宾语或表语，建立所有长难句分析的骨架。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 句子很长、逗号很多、多个动词并存，不确定哪个是谓语。 |
| 主方法 | 先圈连词与标点，再找有时态的人称动词，排除非谓语，确定主句主干。 |
| 替代/验证路线 | 从句尾回看谓语所支配的主语和宾语，验证主谓一致与语义完整。 |
| 复核标准 | 主干能独立成句，谓语数量与连词数量大致匹配，修饰成分可暂时删除。 |
| 易错边界 | 看到动词形式不等于看到谓语；过去分词和现在分词常作修饰或补语。 |
| 典型任务 | 长难句主干、翻译切分、阅读句意题、写作病句。 |
| 达标标准 | 能在 15 秒内标出主句 S-V-O/C，并说明其余成分附着位置。 |

### 本节点七项检查

- [ ] 能识别五种基本句型及常见扩展。
- [ ] 能区分谓语动词、非谓语动词和从句谓语。
- [ ] 能利用时态、人称和连词判断谓语层级。
- [ ] 能暂时删除介词短语、同位语和插入语保留主干。
- [ ] 能判断宾语、表语、宾补和双宾语。
- [ ] 能用主谓一致反查主语边界。
- [ ] 长句分析后能还原为简短、语义完整的主干句。

## G2 三大从句与关系词

判断名词性、定语和状语从句的功能、边界及关系词在从句中的成分。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | that/which/when/where/what 等关系词难区分；从句嵌套；先行词不明显。 |
| 主方法 | 先问从句整体在主句中充当什么成分，再问关系词在从句内部是否缺成分。 |
| 替代/验证路线 | 将从句替换为名词、形容词或副词功能块，检查主句结构是否完整。 |
| 复核标准 | 从句功能、关系词成分和语义关系三者一致。 |
| 易错边界 | 不要只凭先行词是“时间/地点”就选 when/where；关键是从句内部缺什么。 |
| 典型任务 | 关系词选择、长句切分、翻译定语从句、写作从句。 |
| 达标标准 | 能解释 that 与 when/where/which 的选择依据，而非凭中文感觉。 |

### 本节点七项检查

- [ ] 能识别主语、宾语、表语和同位语从句。
- [ ] 能判断定语从句关系词在从句中作主语、宾语或状语。
- [ ] 能区分限制性与非限制性定语从句的作用。
- [ ] 能识别时间、原因、条件、让步、目的、结果、比较状语从句。
- [ ] 能处理介词前置的关系结构。
- [ ] 能判断 what 与 that 的结构差别。
- [ ] 能在嵌套从句中逐层标注起点、终点和附着对象。

## G3 非谓语与压缩结构

识别不定式、动名词、现在分词和过去分词的逻辑主语、时间和语态关系。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 句中多个 -ing/-ed/to do；不知道修饰谁；翻译时关系混乱。 |
| 主方法 | 先找非谓语的逻辑主语，再判断主动/被动与先后关系，最后确定句法功能。 |
| 替代/验证路线 | 将非谓语展开成从句，检查逻辑主语和时间关系是否合理。 |
| 复核标准 | 展开后的从句语义通顺，且与主句不存在悬垂修饰。 |
| 易错边界 | 形式相同功能可不同；-ed 不总表示过去，-ing 不总表示进行。 |
| 典型任务 | 非谓语作定语、状语、补语，独立主格，翻译切分。 |
| 达标标准 | 能把常见非谓语结构双向改写为从句，并保持逻辑关系。 |

### 本节点七项检查

- [ ] 能区分不定式、动名词和分词的核心功能。
- [ ] 能确定非谓语的逻辑主语。
- [ ] 能判断主动、被动、完成和进行关系。
- [ ] 能识别非谓语作定语、状语、宾补和主宾表语。
- [ ] 能识别独立主格和 with 复合结构。
- [ ] 能发现悬垂分词与逻辑主语不一致。
- [ ] 翻译时能把压缩结构展开为自然汉语分句。

## G4 特殊结构：倒装、强调、省略与比较

识别因语序变化或成分省略造成的表面陌生结构，恢复正常语序和完整信息。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 否定词前置、only 前置、it is/was、than/as 后省略、长比较结构。 |
| 主方法 | 先识别结构触发词，恢复正常语序或补全省略，再解释其强调焦点。 |
| 替代/验证路线 | 用普通陈述句改写，检查信息是否等价。 |
| 复核标准 | 改写后主干、否定范围、比较对象和强调焦点清楚。 |
| 易错边界 | 不要见 it is 就判强调；不要忽略否定前移导致的倒装；比较对象必须同类。 |
| 典型任务 | 阅读句意、翻译、完形语法、写作句式。 |
| 达标标准 | 能在不依赖术语的情况下把特殊结构还原并准确解释。 |

### 本节点七项检查

- [ ] 能识别完全倒装与部分倒装。
- [ ] 能识别否定、only、so/such 等触发的倒装。
- [ ] 能检验强调句去掉框架后是否仍为完整句。
- [ ] 能补全并列、比较和从句中的省略成分。
- [ ] 能处理 more/less than、no more than 等比较表达。
- [ ] 能确定否定词的作用范围。
- [ ] 能把特殊语序还原为自然逻辑顺序。

## G5 长难句综合切分与指代

整合主干、从句、非谓语、插入语和指代，形成可复核的句义。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 一句超过两行；多层嵌套；代词、this/that/such 指向不清。 |
| 主方法 | 按“标点/连词切块—主干—修饰附着—指代—逻辑—重组”六步处理。 |
| 替代/验证路线 | 先逐块释义，再用段落主题验证整体论证方向。 |
| 复核标准 | 每个修饰块有明确附着对象，每个代词有可回指内容，句义与段落一致。 |
| 易错边界 | 不要逐词顺译；不要让最近名词原则取代语义和数的一致检查。 |
| 典型任务 | 阅读关键句、翻译划线句、七选五衔接、完形篇章。 |
| 达标标准 | 能画出句子层级并在 60 秒内给出准确、自然的中文释义。 |

### 本节点七项检查

- [ ] 能用标点、并列连词和从属连词切分层级。
- [ ] 能标出主句与各从句的嵌套关系。
- [ ] 能判断介词短语、同位语和插入语的附着对象。
- [ ] 能解析代词、指示词和替代词的回指范围。
- [ ] 能识别句内因果、转折、让步和比较关系。
- [ ] 能先结构后翻译，避免逐词线性处理。
- [ ] 能用原文前后句验证最终句义。

# C · 完形填空

> 以篇章逻辑为主线，综合处理语义、搭配、语法和指代，避免逐空孤立作答。

默认优先级：**B**。优先级会随个人真题数据调整。

## 模块节点总览

| 节点 | 主题 | 学习目标 | 达标证据 |

| C4 | 语法结构与句法约束 | 用句法位置、从句结构、非谓语、时态语态和指代排除不合结构的选项。 | 能明确说出该空是“句法先定”还是“语义先定”。 |

## C1 主题、语义场与上下文方向

先建立文章主题和段落语义场，再判断空格所需的意义方向。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 选项词义相近；单句都通；前后文决定褒贬、因果或对象范围。 |
| 主方法 | 快速通读首段和各段首句，标出主题词、评价方向和重复概念。 |
| 替代/验证路线 | 暂留难空，先完成高确定度空格，用已填信息反哺主题判断。 |
| 复核标准 | 所选词与主题对象、语气方向和局部句义均一致。 |
| 易错边界 | 不要一开始就逐空死磕；局部通顺不等于篇章一致。 |
| 典型任务 | 语境词义、主题一致、褒贬方向、重复概念。 |
| 达标标准 | 能在首轮 2—3 分钟内说出文章主题、立场和主要对立面。 |

### 本节点七项检查

- [ ] 首轮通读能抓住主题对象和作者基本态度。
- [ ] 能标记反复出现的核心概念及其同义改写。
- [ ] 能判断空格需要正向、负向或中性语义。
- [ ] 能利用前后句限制选项的对象范围。
- [ ] 难空会暂留而不是过度消耗时间。
- [ ] 完成后能检查段落语义是否连贯。
- [ ] 能说明答案依赖的篇章证据，而非只说“读起来顺”。

## C2 逻辑关系与连接手段

识别句间和段间的转折、因果、递进、并列、例证、让步与总结关系。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 连接词、副词、介词短语或隐性逻辑选项；前后信息方向变化。 |
| 主方法 | 先不用选项概括前后两句关系，再从选项中找功能和语气强度匹配者。 |
| 替代/验证路线 | 若连接词不明显，检查指代、重复词和情感方向是否形成隐性逻辑。 |
| 复核标准 | 连接后前后命题关系成立，且强弱程度不过度。 |
| 易错边界 | 不能仅凭中文“但是/因此”替换；同类逻辑词在语法位置和强度上不同。 |
| 典型任务 | 逻辑连接词、段落衔接、完形高频功能词。 |
| 达标标准 | 能用“前句命题—关系—后句命题”三段式解释答案。 |

### 本节点七项检查

- [ ] 能区分并列、递进、转折、让步、因果和结果。
- [ ] 能区分例证、解释、改述和总结关系。
- [ ] 能判断连接词在句首、句中或介词结构中的语法位置。
- [ ] 能识别无显式连接词时的隐性逻辑。
- [ ] 能比较同类逻辑词的强度和正式程度。
- [ ] 复盘时能画出段落逻辑链。
- [ ] 能用替换测试验证连接词是否自然。

## C3 词义辨析与固定搭配

利用搭配对象、语义范围和篇章主题区分近义实词。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 四个动词、名词或形容词中文义相近；固定搭配或对象限制决定答案。 |
| 主方法 | 先确定搭配中心与空格词性，再比较对象、介词、语气和语域。 |
| 替代/验证路线 | 将候选词分别与左右词组成词块，检查哪一个最自然。 |
| 复核标准 | 词块自然、句义准确、篇章方向一致。 |
| 易错边界 | 不要只看中文释义；不要因某词“更高级”就选。 |
| 典型任务 | 动词名词搭配、介词搭配、近义词、熟词生义。 |
| 达标标准 | 能把错题整理为“中心词—正确搭配—混淆搭配”三栏。 |

### 本节点七项检查

- [ ] 能先判断空格词性再比较选项。
- [ ] 能利用宾语和介词限制动词选择。
- [ ] 能比较近义名词的对象范围。
- [ ] 能判断形容词的评价色彩和搭配对象。
- [ ] 能识别熟词在当前搭配中的新义。
- [ ] 能把答案还原为完整词块记忆。
- [ ] 七天后能从中心词主动回忆正确搭配。

## C4 语法结构与句法约束

用句法位置、从句结构、非谓语、时态语态和指代排除不合结构的选项。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 选项是代词、关系词、介词、动词形式或词性变化；句意不足以直接判断。 |
| 主方法 | 先分析空格所在结构需要什么成分，再看语义是否符合。 |
| 替代/验证路线 | 补全省略成分或还原从句，验证语法闭合。 |
| 复核标准 | 结构完整、主谓一致、指代清楚、时态语态合理。 |
| 易错边界 | 语法正确只是必要条件；多个语法可行选项仍要靠语义和篇章。 |
| 典型任务 | 关系词、代词、非谓语、时态语态、主谓一致。 |
| 达标标准 | 能明确说出该空是“句法先定”还是“语义先定”。 |

### 本节点七项检查

- [ ] 能判断空格需要词性或句子成分。
- [ ] 能识别关系词在从句中是否缺成分。
- [ ] 能判断非谓语的逻辑主语和语态。
- [ ] 能用时间线判断时态。
- [ ] 能用主宾关系判断主动或被动。
- [ ] 能检查代词数、性和指代对象。
- [ ] 语法排除后仍会回到篇章语义复核。

## C5 两轮作答与全文复核

建立先易后难、局部与整体互证的稳定作答流程。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 单空反复纠结；改答案过多；做完不通读；用时失控。 |
| 主方法 | 第一轮做高确定度空并标记疑问，第二轮用完整篇章复核逻辑和搭配。 |
| 替代/验证路线 | 对低确定度空比较两项证据数量，不因“感觉”随意改。 |
| 复核标准 | 全文读起来主题一致、指代清楚、逻辑闭合，且改动有明确新证据。 |
| 易错边界 | 不要为了“全文顺”而牺牲精确搭配；不要无证据频繁改首选。 |
| 典型任务 | 时间管理、低确定度空、全文通读、错因统计。 |
| 达标标准 | 能在目标时间内完成，并记录每空确定度和错因类型。 |

### 本节点七项检查

- [ ] 有固定的首轮通读和第一轮作答时间。
- [ ] 能标记高、中、低确定度空。
- [ ] 难空会等待后文信息而不是立即猜。
- [ ] 第二轮按逻辑、搭配、语法、指代顺序复核。
- [ ] 改答案前必须写出新增证据。
- [ ] 复盘统计错误属于词汇、逻辑、语法还是时间。
- [ ] 连续三套能在规定时间内稳定完成。

- [ ] 能识别转折、让步和结论后的高权重信息。

- [ ] 能找出贯穿全文的重复概念及同义改写。
- [ ] 能画出段落间因果、对比或递进关系。
- [ ] 能用一句话概括全文中心问题与作者答案。

## R2 细节定位与同义改写

| 字段 | 内容 |

| 替代/验证路线 | 把每个选项反向改写成原文命题，逐项检查对象、范围和因果。 |
| 复核标准 | 正确项与原文在主体、动作、条件、范围和态度上等值。 |
| 易错边界 | 不要只做关键词匹配；原文词复现可能是干扰项诱饵。 |
| 典型任务 | 事实细节、原因细节、指代细节、同义替换。 |
| 达标标准 | 能给每道细节题标出最小证据区间，并解释三个错项的偷换点。 |

### 本节点七项检查

- [ ] 能从题干提取稳定定位词。
- [ ] 能识别题干和原文之间的同义改写。
- [ ] 能把证据区间控制在必要的 1—3 句。
- [ ] 能核对主体、动作、对象、时间和条件。
- [ ] 能识别范围扩大、对象替换和因果倒置。
- [ ] 不会因为选项复现原词就直接选择。
- [ ] 复盘时能记录正确项的改写方式。

## R3 推断、态度与观点边界

从明确证据作最小必要推断，并判断作者或特定人物的态度。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题干出现 infer/imply/suggest/attitude/tone；原文没有答案原句。 |
| 主方法 | 先定位证据，再问“原文至少保证什么”；态度题抓评价词、转折和结论。 |
| 替代/验证路线 | 尝试寻找能直接反驳选项的原文限制条件，优先排除过强推断。 |
| 复核标准 | 推断不超出证据，态度对象明确，语气强度与原文一致。 |
| 易错边界 | 合理常识不等于原文推断；作者引用他人观点不代表赞同。 |
| 典型任务 | 推断题、态度题、观点判断、语气强弱。 |
| 达标标准 | 能写出“证据—桥梁—结论”三步链，桥梁不超过一层。 |

### 本节点七项检查

- [ ] 能区分事实复述、合理推断和无依据想象。
- [ ] 能把推断限制在一层逻辑内。
- [ ] 能识别作者与被引述者的观点边界。
- [ ] 能利用评价形容词、副词和动词判断态度。
- [ ] 能区分谨慎、怀疑、批评、支持等强度。
- [ ] 能排除绝对化和情绪过强的选项。
- [ ] 能用原文限制词校准推断范围。

## R4 词义、指代、例证与句意

处理词句在具体语境中的意义，以及代词、例子和引用的论证功能。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题干问某词/短语/句子含义，或 why does the author mention...。 |
| 主方法 | 先看所在句的结构，再看前后逻辑；例证题向上寻找其支持或反驳的观点。 |
| 替代/验证路线 | 用自拟的简短释义替换原词句，检查是否保持段落方向。 |
| 复核标准 | 释义符合上下文，指代对象在数与语义上匹配，例子功能指向上位观点。 |
| 易错边界 | 不要选词典最熟义；不要把例子本身当作作者最终观点。 |
| 典型任务 | 语境词义、指代、例证作用、长句含义。 |
| 达标标准 | 能用不超过 15 个中文词概括目标词句的语境功能。 |

### 本节点七项检查

- [ ] 能根据句法位置判断目标词词性和作用。
- [ ] 能利用同义、反义、因果和例证线索猜义。
- [ ] 能确定代词的语法和语义回指。
- [ ] 能区分例子的内容与例子的论证目的。
- [ ] 能把复杂句改写成简单命题。
- [ ] 能排除只符合词典义但不符合段落的选项。
- [ ] 复盘时记录目标词句与上位观点的关系。

## R5 主旨、标题与整篇复核

选择覆盖全文、对象准确、范围适中的主旨或标题，并建立稳定作答节奏。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 选项都提到文中内容；一个太宽、一个太窄、一个只写例子、一个接近主线。 |
| 主方法 | 综合首尾段、各段功能和重复概念，先自行概括，再匹配选项。 |
| 替代/验证路线 | 检验候选标题能否解释每一段为何存在，并排除只覆盖局部的选项。 |
| 复核标准 | 主题对象、核心争议和作者倾向均覆盖，范围不过宽也不过窄。 |
| 易错边界 | 生动不等于准确；标题不必包含所有细节，但必须覆盖中心问题。 |
| 典型任务 | 全文主旨、最佳标题、文章目的、时间管理。 |
| 达标标准 | 能在不看选项时先写出 20 字以内主旨，再稳定匹配答案。 |

### 本节点七项检查

- [ ] 能区分主题、中心观点和写作目的。
- [ ] 能用各段功能验证主旨覆盖范围。
- [ ] 能排除只概括某一段或某一例子的选项。
- [ ] 能排除范围过宽、态度过强或对象错误的标题。
- [ ] 能在看选项前形成自己的主旨表达。
- [ ] 有稳定的每篇阅读用时和题目顺序。
- [ ] 做完能回看高风险题而不重新通读全文。

# N · 新题型

> 通过主题、指代、逻辑、词汇复现和结构平行完成七选五、排序与匹配。

默认优先级：**A**。优先级会随个人真题数据调整。

## 模块节点总览

| 节点 | 主题 | 学习目标 | 达标证据 |
| --- | --- | --- | --- |
| N1 | 七选五：局部衔接与全局主题 | 同时利用空前空后和段落主题选择缺失句。 | 能为每个空写出至少两类衔接证据。 |
| N2 | 段落排序：起点、链条与终点 | 用无前指起点、明确回指链和总结终点构建段落顺序。 | 能标出至少三组不可逆的强连接。 |
| N3 | 信息匹配：题干压缩与同义定位 | 把题干压缩成核心命题，在多个段落或人物观点中寻找同义证据。 | 能将题干压缩为一条逻辑命题并标出对应证据。 |
| N4 | 衔接线索：指代、复现与平行 | 建立新题型中可操作的衔接证据层级。 | 能在两个候选都通顺时按证据强弱做出稳定选择。 |
| N5 | 作答顺序、排除与复核 | 先锁定高确定度连接，再利用剩余选项完成全局排除。 | 能在目标时间内完成，并对每空标注主要证据类型。 |

## N1 七选五：局部衔接与全局主题

同时利用空前空后和段落主题选择缺失句。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 空格位于段首、段中或段尾；选项表面都能接上一侧。 |
| 主方法 | 先判空格功能，再找指代、连接词、重复概念和句式平行，最后做全局一致性。 |
| 替代/验证路线 | 把候选句代入并朗读前后两句，检查逻辑和指代是否双向闭合。 |
| 复核标准 | 空前到选项、选项到空后均连贯，且不破坏段落主题。 |
| 易错边界 | 只与前句相连不够；选项中的代词必须有明确前文对象。 |
| 典型任务 | 段首主题句、段中承接句、段尾总结句。 |
| 达标标准 | 能为每个空写出至少两类衔接证据。 |

### 本节点七项检查

- [ ] 能判断空格处需要主题、过渡、例证还是总结。
- [ ] 能利用代词和指示词回指。
- [ ] 能利用转折、因果、递进和并列连接。
- [ ] 能识别词汇复现与同义替换。
- [ ] 能识别句式平行和列表结构。
- [ ] 能同时检查空前和空后。
- [ ] 完成后能通读全文验证主题连续。

## N2 段落排序：起点、链条与终点

用无前指起点、明确回指链和总结终点构建段落顺序。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 多个段落均可作开头；代词、时间、概念引入和举例形成链条。 |
| 主方法 | 先找最少前指的起点，再配对强连接，最后处理弱连接和终点。 |
| 替代/验证路线 | 分别检查时间链、概念链和论证链是否一致。 |
| 复核标准 | 每段前指有来源，新概念先引入后展开，结论位于论证之后。 |
| 易错边界 | 不要只靠“读起来顺”；强回指比泛泛主题相似更可靠。 |
| 典型任务 | 段落排序、固定首段后的链条、局部配对。 |
| 达标标准 | 能标出至少三组不可逆的强连接。 |

### 本节点七项检查

- [ ] 能识别没有前指、适合作为起点的段落。
- [ ] 能识别 this/these/such/the former 等回指。
- [ ] 能用冠词和新旧信息判断概念引入顺序。
- [ ] 能建立时间或事件先后链。
- [ ] 能配对观点与例证、问题与回答。
- [ ] 能识别总结和展望型终点。
- [ ] 完成后能从主题和逻辑两层通读验证。

## N3 信息匹配：题干压缩与同义定位

把题干压缩成核心命题，在多个段落或人物观点中寻找同义证据。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题干与原文几乎不复现相同词；多个段落谈同一主题。 |
| 主方法 | 提取主体、动作、对象、态度和条件，建立同义表达清单后定位。 |
| 替代/验证路线 | 反向检查段落是否完整支持题干全部要素。 |
| 复核标准 | 主体与观点归属准确，条件和强度不丢失。 |
| 易错边界 | 关键词相同不等于命题相同；人物姓名附近不一定就是其观点。 |
| 典型任务 | 标题匹配、人物观点匹配、段落信息匹配。 |
| 达标标准 | 能将题干压缩为一条逻辑命题并标出对应证据。 |

### 本节点七项检查

- [ ] 能把题干拆成主体、动作、对象、态度和条件。
- [ ] 能预测可能出现的同义改写。
- [ ] 能区分段落主题与具体命题。
- [ ] 能核对观点归属和说话者。
- [ ] 能处理一个段落对应多个题干的情况。
- [ ] 能排除只匹配关键词但不匹配关系的段落。
- [ ] 复盘时记录最关键的同义改写。

## N4 衔接线索：指代、复现与平行

建立新题型中可操作的衔接证据层级。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 候选之间主题相似，需比较哪类连接更强。 |
| 主方法 | 按强度排序：明确指代/问答/时间 > 逻辑连接 > 词汇复现 > 泛主题相似。 |
| 替代/验证路线 | 为每个连接写出“前项—线索—后项”三元组。 |
| 复核标准 | 强连接无歧义，弱连接受到全局结构支持。 |
| 易错边界 | 词汇复现可能是干扰；同义并不保证相邻。 |
| 典型任务 | 所有新题型的证据比较与冲突处理。 |
| 达标标准 | 能在两个候选都通顺时按证据强弱做出稳定选择。 |

### 本节点七项检查

- [ ] 能区分强指代、弱复现和泛主题相似。
- [ ] 能识别问答、定义解释和观点例证配对。
- [ ] 能识别平行句式和列表序列。
- [ ] 能利用冠词体现的新旧信息。
- [ ] 能利用时态和时间词判断先后。
- [ ] 能为冲突选项比较证据数量与强度。
- [ ] 能避免只凭单一关键词作答。

## N5 作答顺序、排除与复核

先锁定高确定度连接，再利用剩余选项完成全局排除。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 一开始选项过多；某一空卡住导致整题停滞；最后不通读。 |
| 主方法 | 先做强连接和固定位置，再处理弱连接；保留候选集合而非强行单选。 |
| 替代/验证路线 | 完成后按段落主题、指代和逻辑三层复核。 |
| 复核标准 | 所有选项各得其位，无重复冲突，全文自然连贯。 |
| 易错边界 | 排除法只能缩小范围，最终仍需正向证据；不要被一个错误锁死整题。 |
| 典型任务 | 新题型时间管理、候选表、全局回检。 |
| 达标标准 | 能在目标时间内完成，并对每空标注主要证据类型。 |

### 本节点七项检查

- [ ] 有固定的先强后弱作答顺序。
- [ ] 能使用候选集合而非过早锁定。
- [ ] 某空卡住时会跳过并利用其他空排除。
- [ ] 能记录每个选择的主证据。
- [ ] 完成后通读检查主题连续。
- [ ] 能发现前面错误导致的连锁冲突。
- [ ] 连续三套能在目标时间内稳定完成。

# T · 英译汉

> 以结构准确为底线，以信息完整和自然汉语为目标，逐层拆解并重组划线句。

默认优先级：**A+**。优先级会随个人真题数据调整。

| 节点 | 主题 | 学习目标 | 达标证据 |
| --- | --- | --- | --- |
| T1 | 切分、主干与评分信息点 | 先确定句子骨架和主要信息点，再处理修饰成分。 | 能在落笔前用 20 秒写出结构分块和主干译文。 |
| T2 | 从句、非谓语与修饰关系 | 把英语后置、嵌套和压缩修饰转化为清楚的汉语层次。 | 能对同一句给出至少两种重组方案并选择更自然者。 |

## T1 切分、主干与评分信息点

先确定句子骨架和主要信息点，再处理修饰成分。

| 字段 | 内容 |

| 替代/验证路线 | 把主干单独译出，再逐块附加，检查信息是否完整。 |
| 复核标准 | 主干关系正确，所有关键成分都有落点，中文逻辑清楚。 |
| 易错边界 | 不要一上来从第一个词顺译到最后；不要为流畅而删掉限定条件。 |
| 典型任务 | 长句主干、嵌套从句、评分点分解。 |
| 达标标准 | 能在落笔前用 20 秒写出结构分块和主干译文。 |

### 本节点七项检查

- [ ] 能找出主句谓语和主语。
- [ ] 能按连词和标点划分从句与意群。
- [ ] 能标出不可遗漏的否定、比较、条件和范围。
- [ ] 能先译主干再处理修饰。
- [ ] 能为每个分块确定中文落点。
- [ ] 能检查信息是否重复或遗漏。
- [ ] 能用结构标注解释译文依据。

## T2 从句、非谓语与修饰关系

把英语后置、嵌套和压缩修饰转化为清楚的汉语层次。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 多层定语从句、非谓语、同位语、插入语。 |
| 主方法 | 先确定修饰对象和逻辑关系，再决定前置、后置或拆成独立分句。 |
| 替代/验证路线 | 将非谓语展开为从句，比较哪种汉语结构更自然。 |
| 复核标准 | 修饰对象不串位，层级清楚，长定语不过度堆叠。 |
| 易错边界 | 英语定语不能一律前置；逗号从句不一定都译成“这”。 |
| 典型任务 | 定语从句、同位语、非谓语、插入语翻译。 |
| 达标标准 | 能对同一句给出至少两种重组方案并选择更自然者。 |

### 本节点七项检查

- [ ] 能识别每个从句的功能和先行对象。
- [ ] 能判断限制性与补充性信息。
- [ ] 能把非谓语还原为主动或被动关系。
- [ ] 能处理同位解释和插入评论。
- [ ] 能决定长定语前置、后置或拆句。
- [ ] 能避免修饰对象错位。
- [ ] 能用汉语标点重新组织层次。

## T3 词义选择、抽象名词与代词

在语境中选择自然词义，处理名词化、抽象表达和指代。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 熟词生义、抽象名词连串、it/this/that/they 回指不清。 |
| 主方法 | 先确定词性与搭配，再将抽象名词还原为动作、性质或关系，明确指代对象。 |
| 替代/验证路线 | 用上下文替换测试确认词义，并检查汉语是否需要增补主语或动词。 |
| 复核标准 | 词义准确、指代清楚、抽象表达转化自然。 |
| 易错边界 | 不要把所有名词都硬译成“……性/……化”；不要机械译每个代词。 |
| 典型任务 | 熟词生义、名词化、代词、术语与普通义。 |
| 达标标准 | 能解释关键实词为何取该义，并把抽象名词转成自然汉语。 |

### 本节点七项检查

- [ ] 能根据搭配和论证方向确定实词语境义。
- [ ] 能将动作性名词还原为动词表达。
- [ ] 能将性质性名词转化为形容或判断。
- [ ] 能明确代词和指示词的回指对象。
- [ ] 能区分术语义与普通语境义。
- [ ] 能避免中文空泛词堆叠。
- [ ] 复盘时记录最关键的词义选择证据。

## T4 语序重组、被动与否定比较

按汉语信息顺序重组原句，准确表达被动、否定、比较、让步和因果。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 英文语序直译生硬；被动句无自然主语；否定范围或比较对象易错。 |
| 主方法 | 先写逻辑关系，再选择主动、无主句或被动表达，最后调整时间与因果顺序。 |
| 替代/验证路线 | 把译文回译为逻辑命题，检查否定和比较是否保真。 |
| 复核标准 | 逻辑关系、范围和比较对象准确，汉语顺序自然。 |
| 易错边界 | 被动不必都有“被”；否定词位置改变可能改变命题；比较对象必须同类。 |
| 典型任务 | 被动、否定、比较、让步、因果的汉语化。 |
| 达标标准 | 能在不损失信息的前提下摆脱英文线性语序。 |

### 本节点七项检查

- [ ] 能判断被动是否改为主动或无主句。
- [ ] 能确定否定词作用范围。
- [ ] 能补全省略的比较对象。
- [ ] 能调整原因、结果、条件和让步的顺序。
- [ ] 能处理形式主语和形式宾语。
- [ ] 能避免中文主语频繁跳换。
- [ ] 能回查逻辑命题是否与原文一致。

## T5 成稿、复核与评分稳定性

在结构准确基础上形成完整、通顺、不过度发挥的中文译文。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 结构分析正确但成稿生硬；漏译小词；改写过度。 |
| 主方法 | 按“结构—信息—逻辑—词义—汉语—书写”六层复核。 |
| 替代/验证路线 | 让另一版更直白的译文与成稿对照，检查是否因润色丢信息。 |
| 复核标准 | 译文准确、完整、通顺，关键限定和逻辑标志保留。 |
| 易错边界 | 不追求文学化；不添加作者未表达的评价；不要在一个词上耗时过多。 |
| 典型任务 | 译文润色、漏译检查、限时训练、评分复盘。 |
| 达标标准 | 连续五句在限时内做到主干正确、信息完整、汉语可读。 |

### 本节点七项检查

- [ ] 完成后核对主干关系。
- [ ] 逐块检查有无漏译和重复。
- [ ] 检查否定、比较、时间和逻辑词。
- [ ] 检查代词与主语是否清楚。
- [ ] 删除生硬的英文式长定语。
- [ ] 控制润色，不增添原文没有的信息。
- [ ] 记录每句失分属于结构、词义还是表达。

## W4 论证段落、逻辑链与例证

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 段落只有口号；例子与观点脱节；连接词堆砌。 |

| 替代/验证路线 | 删掉连接词后检查逻辑是否仍成立；例子必须明确服务哪一条观点。 |
| 复核标准 | 每段只有一个中心，论证有因果机制，例子具体且相关。 |
| 易错边界 | 不要用名人名言代替论证；不要编造精确数据；不要每句都用连接词。 |
| 典型任务 | 原因分析、影响、个人社会例证、建议与结论。 |
| 达标标准 | 能写出两段不同角度的论证，每段 4—5 句且逻辑闭合。 |

- [ ] 能解释观点为何成立，而不是重复观点。
- [ ] 能使用个人、社会或制度层面的例证。
- [ ] 能让例证回扣主题句。
- [ ] 能区分原因、结果、对比和让步。
- [ ] 能使用适量连接手段而非机械堆砌。
- [ ] 结尾能总结并给出适度建议。

| 字段 | 内容 |
| --- | --- |

| 复核标准 | 关键句准确，词块自然，句式有变化但不冒险。 |
| 易错边界 | 高级不等于复杂；背诵模板不能替代题目适配；同义词不可随意替换。 |
| 典型任务 | 语法纠错、词块升级、句式变化、重写与评分。 |
| 达标标准 | 同一篇作文在批改后能完成二稿，错误不重复，表达更自然。 |

### 本节点七项检查

- [ ] 能检查主谓一致、时态、语态和非谓语。
- [ ] 能检查冠词、单复数、代词和介词。
- [ ] 能检查搭配与词性。
- [ ] 能用长短句、从句和非谓语适度变化。
- [ ] 能用准确同义表达减少重复。
- [ ] 每篇作文都完成错误标签和二稿重写。
- [ ] 建立个人高正确率句型库并定期淘汰生硬模板。

# 复习闭环与维护系统

## 9.1 每日最小闭环

1. **输入**：完成一小段真题或一个节点训练。
2. **证据**：标出原文证据、结构或写作任务要点。
3. **归因**：使用统一错误标签，不写“粗心”作为终点。
4. **修复**：写一条可迁移规则，制作一个新例或重写一句。
5. **回测**：安排 3/7/14 天主动提取。

## 9.2 节点升级规则

- 0→1：能说清节点研究什么。
- 1→2：有提示可完成常规题。
- 2→3：不同年份真题中稳定正确且用时达标。
- 3→4：能解释错项、边界，并迁移到翻译或写作输出。

## 9.3 A+/A/B/C 优先级

| 优先级 | 含义 | 周训练策略 |
| --- | --- | --- |
| A+ | 高分值或当前明显短板 | 每周至少 3 次，必须回测 |
| A | 高频核心能力 | 每周至少 2 次 |
| B | 性价比中等或基础维护 | 每周 1 次或随真题复盘 |
| C | 低频、已稳定或暂缓内容 | 月度抽查 |

## 9.4 3/7/14 天回测

- **3 天**：遮住解析，重做原题并口述证据。
- **7 天**：做同母题的新题或改写例句。
- **14 天**：放入整篇/整卷中检查迁移和用时。

## 9.5 每周复盘问题

- 本周最高频的三个错误标签是什么？
- 哪个节点“会讲但做不对”，说明掌握证据不足？
- 哪个题型用时波动最大？
- 哪条词汇/句法规则已迁移到写作或翻译？
- 下周唯一最重要的修复目标是什么？

# 高频任务决策树（12 条）

> 决策树解决“看到题后第一步做什么”，不是替代完整分析。

## D-01 生词/熟词生义

**1. 先判词性与句法角色** → **2. 看左右搭配和对象限制** → **3. 看段落主题与褒贬方向** → **4. 比较候选义代回后的信息损失** → **5. 记录语境义与词块**

## D-02 长难句

**1. 圈标点和连词** → **2. 找主句谓语与主干** → **3. 标从句边界和非谓语逻辑主语** → **4. 处理指代与逻辑关系** → **5. 按汉语顺序重组并回文验证**

## D-03 完形单空

**1. 先判断语义/逻辑/搭配/语法主导类型** → **2. 提取本句限制** → **3. 调用段落主题与后文信息** → **4. 比较两个候选的证据数量** → **5. 无新增证据不改首选**

## D-04 阅读细节题

**1. 拆题干主体、动作、对象、条件** → **2. 用稳定定位词回文** → **3. 阅读证据句及前后一句** → **4. 逐项核对范围、因果、态度** → **5. 标最小证据区间**

## D-05 阅读推断题

**1. 先找明确证据** → **2. 写出证据允许的最小结论** → **3. 检查是否跨越超过一层逻辑** → **4. 排除绝对化和常识补充** → **5. 用限制词校准强度**

## D-06 阅读态度题

**1. 确定态度主体与对象** → **2. 抓评价词和转折后信息** → **3. 区分事实引用与作者评价** → **4. 校准正负与强度** → **5. 排除情绪过强选项**

## D-07 主旨/标题题

**1. 标各段功能** → **2. 找重复概念和中心争议** → **3. 先自行概括** → **4. 检查候选能否覆盖每段** → **5. 排除过宽、过窄和局部细节**

## D-08 七选五

**1. 判断空格功能** → **2. 找代词、连接词、复现和平行** → **3. 同时检查空前与空后** → **4. 先锁强连接** → **5. 全文通读检查主题连续**

## D-09 段落排序

**1. 找无前指起点** → **2. 锁定强指代/问答/时间配对** → **3. 连接概念引入与展开** → **4. 确定总结终点** → **5. 用全文逻辑复核**

## D-10 翻译划线句

**1. 切块并找主干** → **2. 确定修饰附着与指代** → **3. 逐块确定词义和逻辑** → **4. 按汉语重组** → **5. 检查信息、否定、比较与流畅度**

## D-11 小作文

**1. 圈身份、对象、目的、要点、语气、格式** → **2. 列 2—3 段功能** → **3. 每个要点补一个具体信息** → **4. 使用高正确率功能句** → **5. 核对任务清单与格式**

## D-12 图画大作文

**1. 客观描述主体与对比** → **2. 提炼适度寓意** → **3. 列两个论证角度** → **4. 每段写机制与例证** → **5. 五遍扫描并安排二稿**

# 错误命题与失效边界库（共 42 张）

> 选择题和复盘中，先用边界卡检查自己是否把“常常成立”误当成“必然成立”。

## 17.2 编号原则

1. 旧编号一旦进入真题/错题记录，尽量不重排。
2. 新节点在同一前缀下追加；弃用节点保留并标记 deprecated。
3. 规则卡使用 `K-节点-序号`，母题使用 `Q-模块序号`。
4. 只在有真实题目或清晰边界时新增卡片，避免为追求数量堆名词。

## 17.3 发布流程

```bash
python scripts/validate_project.py
python scripts/build_bundle.py
zensical build --clean
```

然后更新 `VERSION`、`CHANGELOG.md`，提交分支并创建 Pull Request。

## 17.4 版权边界

- 可记录真题年份、题号、考点、答案证据摘要与自己的解析。
- 不上传未经授权的整套试卷扫描件、文章全文、付费课程讲义或大段教材。
- 原创例句尽量简短，避免复刻真题句子。

本项目默认面向全国硕士研究生招生考试 **英语（一）**。截至 2026 年招生工作规定，英语（一）仍属于全国统一命题科目；外国语科目满分为 100 分。具体题型、能力要求和适用专业仍应以报考年度考试大纲、招生专业目录与报考单位说明为准。

- 全国硕士研究生招生考试：中国教育考试网  
  https://yankao.neea.edu.cn/

  https://yz.chsi.com.cn/kyzx/jybzc/202509/20250925/2293432170-6.html
- 全国硕士研究生招生考试相关政策：中国研究生招生信息网  
  https://yz.chsi.com.cn/

以上入口最后核对日期：**2026-08-25**。后续年度应重新核验，不把旧页面标题当成当年大纲。

## 每年大纲发布后的核对清单

- [ ] 科目名称及英语（一）适用范围是否调整；
- [ ] 考试时间和满分是否调整；
- [ ] 完形、阅读 Part A、Part B、翻译和写作的题量与分值是否调整；
- [ ] 阅读 Part B 的备选题型是否调整；
- [ ] 写作任务类型、字数和评分要求是否调整；
- [ ] 词汇、语法和能力描述是否出现新增或删改；
- [ ] 报考专业是否改考英语（二）或其他外国语科目。

## 版本更新原则

发现官方要求变化时：

1. 在 `CHANGELOG.md` 记录发布日期和影响范围；
2. 更新本页与 `00-overview.md` 的试卷地图；
3. 保留旧节点编号，使用新增、弃用或适用年份标记处理变化；
4. 不根据培训机构转述直接改动核心结构，优先核对官方原文。

    本知识库是一套学习与维护系统，不替代官方大纲、准考证信息、报考单位公告或考场规则。
