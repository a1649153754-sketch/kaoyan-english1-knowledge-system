# Data templates

- `progress.csv`：节点掌握度与复测。
- `questions.csv`：真题/练习题的母题、证据、得分和用时。
- `errors.csv`：错因、迁移规则和复测结果。
- `vocabulary.csv`：语境词义、词块和复习阶段。
- `writing.csv`：作文评分、错误标签和二稿链接。
- `sentences.csv`：长难句骨架、修饰关系、逻辑与复测。
- `translation.csv`：翻译初稿、错误标签、二稿与回译检查。

公开仓库中不要填写个人隐私；敏感数据放入 `private/`（已被 `.gitignore` 忽略）。
