# 上传到 GitHub

默认仓库名：`kaoyan-english1-knowledge-system`。

## 手动命令

```bash
git init
git add .
git commit -m "feat: initialize kaoyan English I knowledge system v1.0.0"
git branch -M main
git remote add origin https://github.com/a1649153754-sketch/kaoyan-english1-knowledge-system.git
git push -u origin main
```

上传后进入 `Settings → Pages`，将 Source 设为 **GitHub Actions**。预计站点：

`https://a1649153754-sketch.github.io/kaoyan-english1-knowledge-system/`

不要把 GitHub 密码、Token、SSH 私钥或验证码写入仓库或发给他人。
