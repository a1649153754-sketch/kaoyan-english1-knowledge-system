# 语境词汇工坊：熟词生义、搭配与主动调用

> 本页解决“背过却认不出、认识却不会用、中文意思相近却选不出”的问题。核心单位不是孤立单词，而是**词性 + 句法角色 + 搭配 + 语境义 + 语气边界**。

## 一、一张有效词卡必须回答什么

| 字段 | 记录内容 |
| --- | --- |
| 词形 | 原形、词性、当前句中的变形 |
| 句法角色 | 主语、谓语、宾语、补语、修饰语或连接成分 |
| 局部搭配 | 左右各 2—4 个词，尤其是中心词、宾语和介词 |
| 最小语境义 | 只写足以解释本句的中文，不抄整页词典 |
| 论证方向 | 正向、负向、中性；支持、反驳、让步或转折 |
| 强度 | 可能、倾向、通常、显著、必然等 |
| 语域 | 学术、正式、中性、口语 |
| 混淆对象 | 最容易误选的词及最小差异 |
| 输出词块 | 一个自己能再次使用的自然搭配 |
| 回测证据 | 3/7/14 天能否在新语境中识别或输出 |

## 二、语境义六维判定

遇到熟词生义或近义词，依次检查：

1. **词性**：当前空位需要名词、动词、形容词还是副词？
2. **对象**：该词通常作用于人、观点、制度、数量还是过程？
3. **搭配**：中心词与宾语、介词、从句结构是否自然？
4. **方向**：作者是在肯定、质疑、限制还是中性描述？
5. **强度**：原文是可能、经常、主要还是必然？
6. **语域**：选项是否比原文更口语、更情绪化或更绝对？

只有六维大致一致，中文“差不多”的词才可能互换。

## 三、30 个高频多义核心词

| 词 | 考研语境中的常见义 | 高频结构/搭配 | 易错边界 |
| --- | --- | --- | --- |
| `address` | 处理、应对；演说；称呼 | `address a problem`, `deliver an address` | 不只表示“地址” |
| `account` | 解释、叙述、账户；占比 | `account for`, `give an account of` | `account for` 可表示解释或占据比例 |
| `assume` | 假定；承担；呈现 | `assume responsibility`, `assume that` | 不总是“想当然” |
| `concern` | 关注的问题；担忧；涉及 | `raise concern`, `be concerned with` | `concerned with` 常表示“涉及” |
| `issue` | 议题、问题；发布、发行 | `a policy issue`, `issue a statement` | 不一定含严重负面色彩 |
| `claim` | 声称；主张；权利要求 | `claim that`, `a claim to` | 阅读中常需区分“作者断言”与“已证事实” |
| `subject` | 主题；研究对象；使遭受 | `be subject to`, `subject A to B` | `be subject to` 可表示受制于或可能受到 |
| `practice` | 实践；惯例；职业活动 | `in practice`, `common practice` | 不只表示“练习” |
| `discipline` | 学科；自律；纪律 | `academic discipline`, `self-discipline` | 语境决定是领域还是行为约束 |
| `faculty` | 能力；院系；教师群体 | `mental faculties`, `the faculty of` | 不只表示“全体教师” |
| `interest` | 兴趣；利益；利害关系 | `public interest`, `have an interest in` | `interests` 常表示利益，不是兴趣 |
| `charge` | 费用；指控；负责 | `in charge of`, `charge a fee`, `charge A with B` | 及物结构不同，含义完全不同 |
| `figure` | 数字；人物；认为；弄清 | `a public figure`, `figure out` | 学术文本中常表示数据或人物 |
| `observe` | 观察到；遵守；庆祝 | `observe a rule`, `observe that` | 不只表示用眼看 |
| `treat` | 对待；处理；视为；治疗 | `treat A as B`, `treat a problem` | 翻译时需明确对象与方式 |
| `present` | 当前的；呈现；提出；在场 | `present evidence`, `at present` | 词性变化会改变重音和含义 |
| `approach` | 方法；接近；着手处理 | `an approach to`, `approach a problem` | 名词后通常接 `to` |
| `matter` | 事情、问题；要紧 | `a matter of`, `it matters whether` | 作动词时表示“重要” |
| `secure` | 获得；确保；使安全 | `secure support`, `secure a position` | 写作中不应一律译为“安全的” |
| `sustain` | 维持；支撑；经受 | `sustain growth`, `sustain an argument` | 可表示使论证成立 |
| `reflect` | 反映；认真思考 | `reflect a trend`, `reflect on` | `reflect on` 与直接宾语义不同 |
| `engage` | 参与；吸引；占用 | `engage in`, `engage readers` | `engage in` 后接活动 |
| `establish` | 建立；确立；证实 | `establish a system`, `establish that` | 研究语境中常表示证实 |
| `maintain` | 维持；保养；坚持主张 | `maintain that`, `maintain standards` | `maintain that` 是“坚持认为” |
| `challenge` | 挑战；难题；质疑 | `challenge an assumption`, `pose a challenge` | 作动词时可表示质疑真实性 |
| `condition` | 状态；条件；使形成习惯 | `under certain conditions`, `be conditioned by` | 复数常指环境或条件 |
| `respect` | 尊重；方面；关于 | `in this respect`, `with respect to` | `in respect of` 不等于“尊敬” |
| `appreciate` | 欣赏；理解；意识到 | `appreciate the difficulty`, `greatly appreciate` | 学术语境常表示充分理解 |
| `term` | 术语；时期；条件 | `in terms of`, `long-term` | `in terms of` 表示“从……角度” |
| `consequence` | 结果、后果 | `as a consequence`, `unintended consequences` | 可能中性，也可能负面，取决于修饰语 |

## 四、十二组近义词最小差异

| 组别 | 最小差异 | 典型搭配 |
| --- | --- | --- |
| `important / significant / crucial` | `important` 泛指重要；`significant` 常指影响明显或统计意义；`crucial` 表示决定性 | `an important issue`, `a significant change`, `a crucial factor` |
| `show / indicate / suggest` | `show` 证据较直接；`indicate` 指向某结论；`suggest` 常保留不确定性 | `data show`, `results indicate`, `evidence suggests` |
| `cause / lead to / contribute to` | `cause` 因果较强；`lead to` 表结果链；`contribute to` 表部分促成 | `cause damage`, `lead to change`, `contribute to growth` |
| `problem / issue / challenge` | `problem` 需解决；`issue` 是讨论事项；`challenge` 强调难度 | `solve a problem`, `address an issue`, `face a challenge` |
| `argue / claim / suggest` | `argue` 给出理由；`claim` 断言；`suggest` 较弱地提出 | `argue that`, `claim that`, `suggest that` |
| `change / shift / transform` | `change` 中性；`shift` 强调方向或重心移动；`transform` 表深层改变 | `change a rule`, `shift attention`, `transform a system` |
| `help / enable / facilitate` | `help` 泛用；`enable` 使具备条件；`facilitate` 使过程更容易 | `help students`, `enable access`, `facilitate communication` |
| `improve / enhance / promote` | `improve` 使变好；`enhance` 提升已有品质；`promote` 促进发展 | `improve accuracy`, `enhance quality`, `promote cooperation` |
| `common / widespread / prevalent` | `common` 常见；`widespread` 分布广；`prevalent` 在某群体中盛行 | `a common error`, `widespread concern`, `a prevalent view` |
| `limit / restrict / constrain` | `limit` 设上限；`restrict` 直接限制活动；`constrain` 受条件约束 | `limit costs`, `restrict access`, `constrain choice` |
| `use / employ / exploit` | `use` 中性；`employ` 较正式；`exploit` 可指充分利用，也可含剥削 | `use a tool`, `employ a method`, `exploit a resource` |
| `result / outcome / consequence` | `result` 泛指结果；`outcome` 常指过程终点；`consequence` 强调由前因产生 | `research result`, `learning outcome`, `social consequence` |

## 五、中文万能词拆分

### `make`

不要看到“使”就只用 `make`：

| 中文功能 | 更自然的英文结构 |
| --- | --- |
| 使某人能够 | `enable somebody to do` |
| 导致结果 | `lead to / result in` |
| 使某物变得…… | `make + object + complement` 或 `render`（高风险，慎用） |
| 产生产品/结果 | `produce / create` |
| 迫使 | `force / compel` |
| 促使、鼓励 | `encourage / prompt` |

先判断因果强度和宾语类型，再选动词。

### `guide`

| 中文功能 | 可选词 | 边界 |
| --- | --- | --- |
| 指导具体行动 | `guide` | 常有明确对象和过程 |
| 指引方向 | `direct` | 强调方向或安排 |
| 为判断提供依据 | `inform` | `information informs decisions` |
| 长期塑造 | `shape` | 影响渐进，不等于完全决定 |
| 引导避开风险 | `steer` | 常见 `steer A away from B` |

## 六、从认识到会用的五级阶梯

1. **识别**：在原句中说出词性和语境义。
2. **改写**：用简单英文或中文解释本句含义。
3. **搭配**：写出中心词的自然宾语、介词或从句结构。
4. **输出**：用该词块造一个原创句。
5. **迁移**：在新主题、新词性或新搭配中仍能正确调用。

只有达到第 4—5 级，词汇才真正进入写作和翻译能力。

## 七、3/7/14 天回测

### 当天

遮住中文义，只看原句，回答：

- 它在句中是什么词性？
- 和谁搭配？
- 语气强度如何？
- 为什么不能用最熟悉的中文义？

### 第 3 天

换一个原创句，判断是否仍能识别该义。

### 第 7 天

给出中文功能，主动写出词块。

### 第 14 天

把该词与最容易混淆的词放在同一题中，说明最小差异。

连续三次跨语境正确，才把卡片降为低频复习。

## 八、与数据表的对应

使用 [`data/vocabulary.csv`](../data/vocabulary.csv) 时：

- `lemma`：记录原形；
- `part_of_speech`：记录本句词性，而不是词典全部词性；
- `context_meaning`：只写最小语境义；
- `collocation`：记录中心词、宾语和介词整体；
- `word_family`：只补充与当前任务有关的词形；
- `source`：写年份、文章或自建练习来源，不粘贴受版权保护的全文；
- `priority`：按错误次数和迁移价值标记；
- `confused_with`：记录混淆对象与最小差异；
- `notes`：记录方向、强度和语域。
