# 考研英语一知识体系 v1.0.0

> 一套面向**考研英语（一）**的可持续知识库：以固定节点、规则卡、母题、反例和个人真题证据组织复习。

## 0.1 项目边界

- 默认科目：**201 英语（一）**。
- 本项目按近年来稳定题型组织，报考年度的题型、分值和要求以教育部教育考试院当年发布的大纲为准。
- 不收录未经授权的整套真题、文章或教材原文；只记录年份、题号、考点、证据摘要和原创例句。
- 英语（二）可在后续版本建立独立分支，避免混用写作与翻译要求。

## 0.4 掌握等级

| 等级 | 含义 | 升级证据 |
| ---: | --- | --- |
| 0 | 未接触或无法识别 | 能说明学习对象 |
| 1 | 认识概念但不会独立处理 | 能在提示下完成 |
| 2 | 常规题能做但不稳定 | 真题正确且能解释证据 |
| 3 | 稳定独立完成 | 多年份迁移、用时达标 |
| 4 | 能讲清边界并迁移输出 | 能纠错、改写、设计反例或二稿 |

## 0.5 默认个人优先级

结合既往表现，当前先将**翻译和写作设为 A+，词汇/句法与方法系统设为 A+，阅读设为 A，新题型设为 A，完形设为 B**。这只是 v1.0 基线，后续必须用真题正确率和用时覆盖主观判断。

## 0.6 错误标签

| 标签 | 含义 |
| --- | --- |
| LEX | 词义、搭配、词形或词汇调用错误 |
| SYN | 句法结构、从句、非谓语或指代错误 |
| LOG | 句间/段间逻辑关系判断错误 |
| EVI | 定位或证据匹配错误 |
| INF | 推断越界、范围或态度强度错误 |
| TIME | 时间分配、跳题或复核策略错误 |
| EXP | 翻译或写作表达不自然、不准确 |
| FMT | 应用文格式、拼写、标点或书写错误 |

## 0.7 使用闭环

1. 学一个节点，只记录概念、触发信号、主方法、边界和达标证据。
2. 做题后挂到 `Q` 母题与节点编号。
3. 错题贴 `LEX/SYN/LOG/EVI/INF/TIME/EXP/FMT` 标签。
4. 生成一句迁移规则，安排 3/7/14 天复测。
5. 每周只主攻 3—5 个 A+/A 节点，依据证据升降级。
