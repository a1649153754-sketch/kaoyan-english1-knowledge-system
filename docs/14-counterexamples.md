# 错误命题与失效边界库（共 42 张）

> 选择题和复盘中，先用边界卡检查自己是否把“常常成立”误当成“必然成立”。

| 边界 ID | 错误命题 | 正确版本 | 最小反例/失效原因 |
| --- | --- | --- | --- |
| B-V01 | 一个英文单词只有一个固定中文意思。 | 词义由词性、搭配和语境共同决定。 | 同一常见词在法律、经济和日常语境中可对应不同中文。 |
| B-V02 | 中文意思相近的英文词可以互换。 | 需同时检查对象、搭配、强度和语域。 | “导致”类动词对主语、宾语和褒贬方向常有不同限制。 |
| B-V03 | 看到熟词就用最熟悉的释义。 | 熟词也必须按本句句法和搭配定意义。 | 常见动词作抽象义时与日常动作义完全不同。 |
| B-V04 | 构词法能直接确定生词准确含义。 | 构词法只能缩小范围，最终需语境校正。 | 同一词根加不同前缀后可能产生专业化或习惯化意义。 |
| B-V05 | 高级词一定比常用词更好。 | 准确、自然、搭配正确优先于生僻。 | 写作中生僻近义词搭配错误会比常用词更扣分。 |
| B-V06 | 背过中文释义就算掌握词汇。 | 掌握需能在新语境识别并以词块输出。 | 看到单词卡会、文章中仍认不出，说明提取线索过单一。 |
| B-G01 | 句子里每个动词形式都是谓语。 | 谓语需有时态/情态并处于相应分句中。 | 分词和不定式可作定语、状语或补语。 |
| B-G02 | 先行词是时间词就一定用 when。 | 关系词取决于从句内部缺主宾还是缺状语。 | 从句缺宾语时即使先行词表示时间也可能用 which/that。 |
| B-G03 | that 在所有从句中都作成分。 | 名词性从句中的连接 that 常不作成分。 | 宾语从句结构完整仍可由 that 引导。 |
| B-G04 | -ed 表示过去，-ing 表示进行。 | 非谓语形式主要体现语态、逻辑关系和相对时间。 | 过去分词作定语可表示被动状态而非过去时间。 |
| B-G05 | it is/was...that... 一定是强调句。 | 去掉框架后仍为完整句才可能是强调结构。 | 形式主语结构去掉框架后句子不完整。 |
| B-G06 | 代词总指最近的名词。 | 需综合数、语义、句法和篇章中心判断。 | 最近名词在语义上不可能执行后续动作。 |
| B-G07 | 长句按英文顺序逐词翻译最准确。 | 应先建层级，再按汉语逻辑重组。 | 多层后置定语直译会造成修饰错位。 |
| B-G08 | 语法分析越细越好。 | 分析应服务于理解和作答，只拆影响句义的结构。 | 给每个词贴术语却无法说明主干和逻辑，属于无效分析。 |
| B-C01 | 完形每一空都能只靠本句解决。 | 不少空依赖段落主题、后文信息或全文语义场。 | 局部两个选项均通，后文重复概念才决定答案。 |
| B-C02 | 连接词中文相近就可以互换。 | 同类连接词在语法位置、强度和语域上有差异。 | 介词短语与句子副词不能占据相同句法位置。 |
| B-C03 | 语法正确的选项就是答案。 | 结构正确只是必要条件，还需语义与篇章一致。 | 多个选项都符合词性，但只有一个符合搭配和主题。 |
| B-C04 | 做完后把不顺的地方都改掉。 | 改答案必须有新增证据。 | 全文陌生感可能来自话题，而不是原选择错误。 |
| B-C05 | 完形分值低，可以完全放弃。 | 应按个人性价比分配时间，但保留基础得分和整体训练。 | 词汇、逻辑和句法能力会迁移到阅读与新题型。 |
| B-R01 | 正确选项一定复现原文关键词。 | 正确项常通过同义改写表达，原词复现也可能是诱饵。 | 错项复制原词却偷换主体或因果。 |
| B-R02 | 原文没直接说，所以推断题可凭常识。 | 推断必须由文本证据作最小延伸。 | 常识正确但文章未涉及，仍不能选。 |
| B-R03 | 作者引用某观点就表示赞同。 | 需看引语后的评价、转折和全文立场。 | 作者可引用某说法作为反驳对象。 |
| B-R04 | more、all、never 等强词更有力度，所以更像答案。 | 选项强度必须与原文限定一致。 | 原文说 may，选项改成 must 即越界。 |
| B-R05 | 例证题答案就是例子描述的事实。 | 答案通常是例子服务的上位观点。 | 例子讲个人经历，段落中心可能是制度性问题。 |
| B-R06 | 主旨题选择包含信息最多的选项。 | 应选择覆盖中心争议且范围合适的选项。 | 罗列多个细节仍可能没有作者核心观点。 |
| B-R07 | 阅读每句话都必须完全翻译。 | 做题以结构和证据为核心，非关键句可只抓功能。 | 逐句翻译常导致时间失控且不提升定位。 |
| B-R08 | 两个选项都合理时选更符合现实的。 | 选择更受原文支持、范围更精确者。 | 现实上可能但文章没有证据的选项仍错误。 |
| B-R09 | 态度题只看正负即可。 | 还要判断态度对象和强弱，如谨慎、怀疑、批评。 | 对现象担忧不等于对相关研究者敌视。 |
| B-N01 | 七选五只需看空前一句。 | 需同时检查空前、候选和空后。 | 候选能接前句却与空后代词断裂。 |
| B-N02 | 出现相同词的段落一定相邻。 | 词汇复现只是弱证据，明确指代和逻辑更强。 | 相同主题词可贯穿全文而不构成相邻关系。 |
| B-N03 | 排序题按时间词排序就一定正确。 | 还需检查概念引入、指代和论证关系。 | 多个段落描述同一阶段，时间词不足以唯一确定。 |
| B-N04 | 剩余选项自动就是答案。 | 排除后仍需正向衔接证据。 | 前一空选错会导致后续“剩余法”连锁错误。 |
| B-N05 | 段首一定没有连接词。 | 段首可承接前段，但若作为全文起点通常避免强前指。 | 段内新段首可用 however 承接上一段。 |
| B-T01 | 翻译越自由越自然，越容易得分。 | 自然表达不能牺牲原文信息、范围和逻辑。 | 润色时删去条件从句会造成信息缺失。 |
| B-T02 | 所有被动句都译成“被”。 | 可按汉语习惯改主动、无主句或保留被动。 | “普遍认为”常比“被普遍认为”自然。 |
| B-T03 | 每个英语词都必须有一个中文词对应。 | 翻译以命题信息为单位，可增减虚词但不能丢实义。 | 形式主语 it 通常无需逐字落译。 |
| B-T04 | 长定语全部前置最忠实。 | 过长修饰应后置或拆句，保持对象清楚。 | 多层定语前置会让中文中心词迟迟不出现。 |
| B-W01 | 作文模板越复杂越稳。 | 稳定来自任务适配和高正确率句型，不来自固定长模板。 | 模板与题目对象不匹配会显得空泛甚至跑题。 |
| B-W02 | 高级词越多分数越高。 | 准确搭配、清晰论证和低错误率优先。 | 生僻词误用会破坏句义。 |
| B-W03 | 图画作文可以随意补充故事让内容丰富。 | 描述应限于可见信息，论证可合理展开。 | 编造人物身份和事件背景可能偏题。 |
| B-W04 | 名人名言可以替代论证。 | 引用只能辅助，仍需解释观点的机制和联系。 | 一句泛化名言不能证明具体主题。 |
| B-W05 | 写完看答案范文就等于复盘。 | 必须标错、改句并完成二稿才能形成迁移。 | 只阅读范文不会自动修复自己的重复错误。 |
