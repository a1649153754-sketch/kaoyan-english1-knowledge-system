## V · 词汇与语义

### V1 语境词义与一词多义

- [ ] V1-1: 能区分词典核心义、常见引申义和本句语境义。
- [ ] V1-2: 能通过主语、宾语和介词搭配排除不合句法的释义。
- [ ] V1-3: 能利用段落主题判断词义的褒义、贬义或中性方向。
- [ ] V1-4: 遇到熟词生义时先回到句法位置，不被最熟悉的中文义锁死。
- [ ] V1-5: 能比较两个中文近义选项在英文搭配和语气上的差别。
- [ ] V1-6: 词汇笔记同时记录原句、词性、搭配和语境义。
- [ ] V1-7: 七天后只看原句仍能还原该词在文中的意义。

### V2 构词法与词形判断

- [ ] V2-1: 能从冠词、介词、系动词和修饰关系判断空位所需词性。
- [ ] V2-2: 掌握常见否定、反向、程度、时间和数量前缀的方向作用。
- [ ] V2-3: 掌握常见名词、动词、形容词、副词后缀及常见例外。
- [ ] V2-4: 能识别词根相同但词性、及物性或褒贬方向不同的词。
- [ ] V2-5: 遇到长词能先保留词根核心，再结合句法推断。
- [ ] V2-6: 能用词族表整理 noun/verb/adj/adv，而不是只记一个词形。
- [ ] V2-7: 写作复核时能发现形容词副词、单复数和派生词错误。

### V3 搭配、短语与介词系统

- [ ] V3-1: 能识别动词与宾语之间的选择限制。
- [ ] V3-2: 能识别形容词、名词后常接的介词结构。
- [ ] V3-3: 能区分形式相近但方向不同的短语动词。
- [ ] V3-4: 搭配笔记以词块为单位，不以孤立单词为单位。
- [ ] V3-5: 能判断搭配属于书面、口语、正式或中性语域。
- [ ] V3-6: 写作时优先使用确定无误的高频搭配，避免生造。
- [ ] V3-7: 复盘时能说明错误是词义错、介词错还是搭配对象错。

### V4 同义词、反义词与语气强度

- [ ] V4-1: 能区分程度强弱，如倾向、可能、必然等不同力度。
- [ ] V4-2: 能区分事实描述词与带评价色彩的词。
- [ ] V4-3: 能识别选项将部分范围扩大为全部范围。
- [ ] V4-4: 能识别同义改写中的词性转换和上下义替换。
- [ ] V4-5: 写作替换前先检查语域和搭配，而不是盲目追求高级词。
- [ ] V4-6: 建立正向、负向、中性评价词组，而不是只背中文。
- [ ] V4-7: 能通过原文限定词校准选项语气强度。

### V5 词汇记忆与复习闭环

- [ ] V5-1: 词汇按真题来源、主题和错误次数标记优先级。
- [ ] V5-2: 每张词卡只保留与当前语境相关的必要信息。

- [ ] V5-6: 每周淘汰已稳定掌握的卡片，避免复习队列无限膨胀。
- [ ] V5-7: 每月用新文章抽查词汇迁移，而非只复习旧卡。
