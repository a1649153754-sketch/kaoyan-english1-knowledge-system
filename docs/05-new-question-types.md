# N · 新题型

> 通过主题、指代、逻辑、词汇复现和结构平行完成七选五、排序与匹配。

默认优先级：**A**。优先级会随个人真题数据调整。

## N1 七选五：局部衔接与全局主题

同时利用空前空后和段落主题选择缺失句。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 空格位于段首、段中或段尾；选项表面都能接上一侧。 |
| 主方法 | 先判空格功能，再找指代、连接词、重复概念和句式平行，最后做全局一致性。 |
| 替代/验证路线 | 把候选句代入并朗读前后两句，检查逻辑和指代是否双向闭合。 |
| 复核标准 | 空前到选项、选项到空后均连贯，且不破坏段落主题。 |
| 易错边界 | 只与前句相连不够；选项中的代词必须有明确前文对象。 |
| 典型任务 | 段首主题句、段中承接句、段尾总结句。 |
| 达标标准 | 能为每个空写出至少两类衔接证据。 |

### 本节点七项检查

- [ ] 能判断空格处需要主题、过渡、例证还是总结。
- [ ] 能利用代词和指示词回指。
- [ ] 能利用转折、因果、递进和并列连接。
- [ ] 能识别词汇复现与同义替换。
- [ ] 能识别句式平行和列表结构。
- [ ] 能同时检查空前和空后。
- [ ] 完成后能通读全文验证主题连续。

## N2 段落排序：起点、链条与终点

用无前指起点、明确回指链和总结终点构建段落顺序。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 多个段落均可作开头；代词、时间、概念引入和举例形成链条。 |
| 主方法 | 先找最少前指的起点，再配对强连接，最后处理弱连接和终点。 |
| 替代/验证路线 | 分别检查时间链、概念链和论证链是否一致。 |
| 复核标准 | 每段前指有来源，新概念先引入后展开，结论位于论证之后。 |
| 易错边界 | 不要只靠“读起来顺”；强回指比泛泛主题相似更可靠。 |
| 典型任务 | 段落排序、固定首段后的链条、局部配对。 |
| 达标标准 | 能标出至少三组不可逆的强连接。 |

### 本节点七项检查

- [ ] 能识别没有前指、适合作为起点的段落。
- [ ] 能识别 this/these/such/the former 等回指。
- [ ] 能用冠词和新旧信息判断概念引入顺序。
- [ ] 能建立时间或事件先后链。
- [ ] 能配对观点与例证、问题与回答。
- [ ] 能识别总结和展望型终点。
- [ ] 完成后能从主题和逻辑两层通读验证。

## N3 信息匹配：题干压缩与同义定位

把题干压缩成核心命题，在多个段落或人物观点中寻找同义证据。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题干与原文几乎不复现相同词；多个段落谈同一主题。 |
| 主方法 | 提取主体、动作、对象、态度和条件，建立同义表达清单后定位。 |
| 替代/验证路线 | 反向检查段落是否完整支持题干全部要素。 |
| 复核标准 | 主体与观点归属准确，条件和强度不丢失。 |
| 易错边界 | 关键词相同不等于命题相同；人物姓名附近不一定就是其观点。 |
| 典型任务 | 标题匹配、人物观点匹配、段落信息匹配。 |
| 达标标准 | 能将题干压缩为一条逻辑命题并标出对应证据。 |

### 本节点七项检查

- [ ] 能把题干拆成主体、动作、对象、态度和条件。
- [ ] 能预测可能出现的同义改写。
- [ ] 能区分段落主题与具体命题。
- [ ] 能核对观点归属和说话者。
- [ ] 能处理一个段落对应多个题干的情况。
- [ ] 能排除只匹配关键词但不匹配关系的段落。
- [ ] 复盘时记录最关键的同义改写。

## N4 衔接线索：指代、复现与平行

建立新题型中可操作的衔接证据层级。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 候选之间主题相似，需比较哪类连接更强。 |
| 主方法 | 按强度排序：明确指代/问答/时间 > 逻辑连接 > 词汇复现 > 泛主题相似。 |
| 替代/验证路线 | 为每个连接写出“前项—线索—后项”三元组。 |
| 复核标准 | 强连接无歧义，弱连接受到全局结构支持。 |
| 易错边界 | 词汇复现可能是干扰；同义并不保证相邻。 |
| 典型任务 | 所有新题型的证据比较与冲突处理。 |
| 达标标准 | 能在两个候选都通顺时按证据强弱做出稳定选择。 |

### 本节点七项检查

- [ ] 能区分强指代、弱复现和泛主题相似。
- [ ] 能识别问答、定义解释和观点例证配对。
- [ ] 能识别平行句式和列表序列。
- [ ] 能利用冠词体现的新旧信息。
- [ ] 能利用时态和时间词判断先后。
- [ ] 能为冲突选项比较证据数量与强度。
- [ ] 能避免只凭单一关键词作答。

## N5 作答顺序、排除与复核

先锁定高确定度连接，再利用剩余选项完成全局排除。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 一开始选项过多；某一空卡住导致整题停滞；最后不通读。 |
| 主方法 | 先做强连接和固定位置，再处理弱连接；保留候选集合而非强行单选。 |
| 替代/验证路线 | 完成后按段落主题、指代和逻辑三层复核。 |
| 复核标准 | 所有选项各得其位，无重复冲突，全文自然连贯。 |
| 易错边界 | 排除法只能缩小范围，最终仍需正向证据；不要被一个错误锁死整题。 |
| 典型任务 | 新题型时间管理、候选表、全局回检。 |
| 达标标准 | 能在目标时间内完成，并对每空标注主要证据类型。 |

### 本节点七项检查

- [ ] 有固定的先强后弱作答顺序。
- [ ] 能使用候选集合而非过早锁定。
- [ ] 某空卡住时会跳过并利用其他空排除。
- [ ] 能记录每个选择的主证据。
- [ ] 完成后通读检查主题连续。
- [ ] 能发现前面错误导致的连锁冲突。
- [ ] 连续三套能在目标时间内稳定完成。
