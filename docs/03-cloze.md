# C · 完形填空

> 以篇章逻辑为主线，综合处理语义、搭配、语法和指代，避免逐空孤立作答。

默认优先级：**B**。优先级会随个人真题数据调整。

## 模块节点总览

| --- | --- | --- | --- |

## C1 主题、语义场与上下文方向

先建立文章主题和段落语义场，再判断空格所需的意义方向。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 选项词义相近；单句都通；前后文决定褒贬、因果或对象范围。 |
| 主方法 | 快速通读首段和各段首句，标出主题词、评价方向和重复概念。 |
| 替代/验证路线 | 暂留难空，先完成高确定度空格，用已填信息反哺主题判断。 |
| 复核标准 | 所选词与主题对象、语气方向和局部句义均一致。 |
| 易错边界 | 不要一开始就逐空死磕；局部通顺不等于篇章一致。 |
| 典型任务 | 语境词义、主题一致、褒贬方向、重复概念。 |
| 达标标准 | 能在首轮 2—3 分钟内说出文章主题、立场和主要对立面。 |

### 本节点七项检查

- [ ] 首轮通读能抓住主题对象和作者基本态度。
- [ ] 能标记反复出现的核心概念及其同义改写。
- [ ] 能判断空格需要正向、负向或中性语义。
- [ ] 能利用前后句限制选项的对象范围。
- [ ] 难空会暂留而不是过度消耗时间。
- [ ] 完成后能检查段落语义是否连贯。
- [ ] 能说明答案依赖的篇章证据，而非只说“读起来顺”。

## C2 逻辑关系与连接手段

识别句间和段间的转折、因果、递进、并列、例证、让步与总结关系。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 连接词、副词、介词短语或隐性逻辑选项；前后信息方向变化。 |
| 主方法 | 先不用选项概括前后两句关系，再从选项中找功能和语气强度匹配者。 |
| 替代/验证路线 | 若连接词不明显，检查指代、重复词和情感方向是否形成隐性逻辑。 |
| 复核标准 | 连接后前后命题关系成立，且强弱程度不过度。 |
| 易错边界 | 不能仅凭中文“但是/因此”替换；同类逻辑词在语法位置和强度上不同。 |
| 典型任务 | 逻辑连接词、段落衔接、完形高频功能词。 |
| 达标标准 | 能用“前句命题—关系—后句命题”三段式解释答案。 |

### 本节点七项检查

- [ ] 能区分并列、递进、转折、让步、因果和结果。
- [ ] 能区分例证、解释、改述和总结关系。
- [ ] 能判断连接词在句首、句中或介词结构中的语法位置。
- [ ] 能识别无显式连接词时的隐性逻辑。
- [ ] 能比较同类逻辑词的强度和正式程度。
- [ ] 复盘时能画出段落逻辑链。
- [ ] 能用替换测试验证连接词是否自然。

## C3 词义辨析与固定搭配

利用搭配对象、语义范围和篇章主题区分近义实词。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 四个动词、名词或形容词中文义相近；固定搭配或对象限制决定答案。 |
| 主方法 | 先确定搭配中心与空格词性，再比较对象、介词、语气和语域。 |
| 替代/验证路线 | 将候选词分别与左右词组成词块，检查哪一个最自然。 |
| 复核标准 | 词块自然、句义准确、篇章方向一致。 |
| 易错边界 | 不要只看中文释义；不要因某词“更高级”就选。 |
| 典型任务 | 动词名词搭配、介词搭配、近义词、熟词生义。 |
| 达标标准 | 能把错题整理为“中心词—正确搭配—混淆搭配”三栏。 |

### 本节点七项检查

- [ ] 能先判断空格词性再比较选项。
- [ ] 能利用宾语和介词限制动词选择。
- [ ] 能比较近义名词的对象范围。
- [ ] 能判断形容词的评价色彩和搭配对象。
- [ ] 能识别熟词在当前搭配中的新义。
- [ ] 能把答案还原为完整词块记忆。
- [ ] 七天后能从中心词主动回忆正确搭配。

## C4 语法结构与句法约束

用句法位置、从句结构、非谓语、时态语态和指代排除不合结构的选项。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 选项是代词、关系词、介词、动词形式或词性变化；句意不足以直接判断。 |
| 主方法 | 先分析空格所在结构需要什么成分，再看语义是否符合。 |
| 替代/验证路线 | 补全省略成分或还原从句，验证语法闭合。 |
| 复核标准 | 结构完整、主谓一致、指代清楚、时态语态合理。 |
| 易错边界 | 语法正确只是必要条件；多个语法可行选项仍要靠语义和篇章。 |
| 典型任务 | 关系词、代词、非谓语、时态语态、主谓一致。 |
| 达标标准 | 能明确说出该空是“句法先定”还是“语义先定”。 |

### 本节点七项检查

- [ ] 能判断空格需要词性或句子成分。
- [ ] 能识别关系词在从句中是否缺成分。
- [ ] 能判断非谓语的逻辑主语和语态。
- [ ] 能用时间线判断时态。
- [ ] 能用主宾关系判断主动或被动。
- [ ] 能检查代词数、性和指代对象。
- [ ] 语法排除后仍会回到篇章语义复核。

## C5 两轮作答与全文复核

建立先易后难、局部与整体互证的稳定作答流程。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 单空反复纠结；改答案过多；做完不通读；用时失控。 |
| 主方法 | 第一轮做高确定度空并标记疑问，第二轮用完整篇章复核逻辑和搭配。 |
| 替代/验证路线 | 对低确定度空比较两项证据数量，不因“感觉”随意改。 |
| 复核标准 | 全文读起来主题一致、指代清楚、逻辑闭合，且改动有明确新证据。 |
| 易错边界 | 不要为了“全文顺”而牺牲精确搭配；不要无证据频繁改首选。 |
| 典型任务 | 时间管理、低确定度空、全文通读、错因统计。 |
| 达标标准 | 能在目标时间内完成，并记录每空确定度和错因类型。 |

### 本节点七项检查

- [ ] 有固定的首轮通读和第一轮作答时间。
- [ ] 能标记高、中、低确定度空。
- [ ] 难空会等待后文信息而不是立即猜。
- [ ] 第二轮按逻辑、搭配、语法、指代顺序复核。
- [ ] 改答案前必须写出新增证据。
- [ ] 复盘统计错误属于词汇、逻辑、语法还是时间。
- [ ] 连续三套能在规定时间内稳定完成。
