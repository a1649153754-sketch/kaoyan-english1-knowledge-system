# 考研英语一知识体系

> 从“背单词、做阅读、背模板”升级为“识别任务—调用方法—核对证据—追踪错因—完成回测”的长期项目。

![项目封面](assets/images/social-preview.svg)

<div class="grid cards" markdown>

-   **280 个三级检查项**

    覆盖词汇、句法、完形、阅读、新题型、翻译、写作与方法系统。

-   **160 张核心规则卡**

    每张同时记录触发信号、主路线、复核方式和失效边界。

-   **56 类真题母题**

    重点训练看到题目后的第一动作和最小证据链。

-   **42 张边界卡**

    专门处理“看起来合理但并非原文支持”的常见错误。

</div>
