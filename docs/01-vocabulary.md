# V · 词汇与语义

> 把单词从“中文释义表”升级为可在语境中识别词义、搭配、语气和句法位置的网络。

默认优先级：**A+**。优先级会随个人真题数据调整。

## V1 语境词义与一词多义

根据上下文、搭配和论证方向确定词在当前句中的可译义，而不是背诵唯一中文释义。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 选项均认识却难以取舍；熟词放入句中不通；同一词在不同文章中译法变化。 |
| 主方法 | 先定词性与句法角色，再看左右搭配、段落主题和褒贬方向，最后选择最小充分释义。 |
| 替代/验证路线 | 把候选义分别代回原句，比较哪一个最符合主谓宾关系和上下文逻辑。 |
| 复核标准 | 替换后句意、语气和论证方向同时成立，且不额外添加原文没有的信息。 |
| 易错边界 | 词典首义不等于语境义；中文近义不等于英文可互换；不要脱离句子单独拍脑袋。 |
| 典型任务 | 熟词生义、词义猜测、完形近义词、翻译词义选择。 |
| 达标标准 | 能在 20 秒内说明“词性—搭配—语境—最终义”四步证据。 |

### 本节点七项检查

- [ ] 能区分词典核心义、常见引申义和本句语境义。
- [ ] 能通过主语、宾语和介词搭配排除不合句法的释义。
- [ ] 能利用段落主题判断词义的褒义、贬义或中性方向。
- [ ] 遇到熟词生义时先回到句法位置，不被最熟悉的中文义锁死。
- [ ] 能比较两个中文近义选项在英文搭配和语气上的差别。
- [ ] 词汇笔记同时记录原句、词性、搭配和语境义。
- [ ] 七天后只看原句仍能还原该词在文中的意义。

## V2 构词法与词形判断

利用词根、前后缀和词形变化推断词性、方向和大致语义。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 遇到生词但能辨认词根；选项词根相同而词性不同；句中需要名词、动词、形容词或副词。 |
| 主方法 | 先判断空位所需词性，再拆前缀—词根—后缀，最后结合语境校正。 |
| 替代/验证路线 | 若构词信息不足，退回同位结构、并列结构和搭配限制进行判断。 |
| 复核标准 | 词形必须同时满足句法位置、语义方向和固定搭配。 |
| 易错边界 | 构词法只能给出范围，不能替代上下文；相同后缀并不保证词性或含义完全一致。 |
| 典型任务 | 完形词形选择、生词猜义、阅读长词拆解、写作词性纠错。 |
| 达标标准 | 能拆解常见前后缀并说出其“方向作用”，而非死背中文。 |

### 本节点七项检查

- [ ] 能从冠词、介词、系动词和修饰关系判断空位所需词性。
- [ ] 掌握常见否定、反向、程度、时间和数量前缀的方向作用。
- [ ] 掌握常见名词、动词、形容词、副词后缀及常见例外。
- [ ] 能识别词根相同但词性、及物性或褒贬方向不同的词。
- [ ] 遇到长词能先保留词根核心，再结合句法推断。
- [ ] 能用词族表整理 noun/verb/adj/adv，而不是只记一个词形。
- [ ] 写作复核时能发现形容词副词、单复数和派生词错误。

## V3 搭配、短语与介词系统

把动词—名词、形容词—介词、名词—介词和短语动词作为整体调用。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 单词单看都通顺，但只有一个符合固定或高频搭配；介词选项难以区分。 |
| 主方法 | 先找搭配中心词，再检查其常见宾语、介词和语域，最后看语义是否贴合。 |
| 替代/验证路线 | 将表达改写成更熟悉的同义结构，验证介词关系和动作方向。 |
| 复核标准 | 搭配成立、语义自然、语域合适，三者缺一不可。 |
| 易错边界 | 不要把中文介词逐字映射到英文；短语动词意义常不能由单个小词机械相加。 |
| 典型任务 | 完形搭配题、阅读固定表达、翻译短语、写作表达升级。 |
| 达标标准 | 能为高频核心词建立至少 3 个真实搭配，并能在句中正确变形。 |

### 本节点七项检查

- [ ] 能识别动词与宾语之间的选择限制。
- [ ] 能识别形容词、名词后常接的介词结构。
- [ ] 能区分形式相近但方向不同的短语动词。
- [ ] 搭配笔记以词块为单位，不以孤立单词为单位。
- [ ] 能判断搭配属于书面、口语、正式或中性语域。
- [ ] 写作时优先使用确定无误的高频搭配，避免生造。
- [ ] 复盘时能说明错误是词义错、介词错还是搭配对象错。

## V4 同义词、反义词与语气强度

区分近义词在范围、程度、立场、语域和搭配上的细微差别。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 四个选项中文都可译成相似词；阅读选项通过换词改写原文；写作需要避免重复。 |
| 主方法 | 比较五个维度：对象范围、程度强弱、褒贬态度、典型搭配、正式程度。 |
| 替代/验证路线 | 寻找原文中的程度副词、限定词和评价词，作为强度与立场标尺。 |
| 复核标准 | 同义替换必须保持命题范围和态度强度，不可只看中文大意。 |
| 易错边界 | “意思差不多”不是可互换；强词替弱词、全称替部分都可能制造错误选项。 |
| 典型任务 | 阅读同义改写、态度题、完形近义辨析、写作替换。 |
| 达标标准 | 能用一句话说清两个近义词的最小差异，并各给一个自然搭配。 |

### 本节点七项检查

- [ ] 能区分程度强弱，如倾向、可能、必然等不同力度。
- [ ] 能区分事实描述词与带评价色彩的词。
- [ ] 能识别选项将部分范围扩大为全部范围。
- [ ] 能识别同义改写中的词性转换和上下义替换。
- [ ] 写作替换前先检查语域和搭配，而不是盲目追求高级词。
- [ ] 建立正向、负向、中性评价词组，而不是只背中文。
- [ ] 能通过原文限定词校准选项语气强度。

## V5 词汇记忆与复习闭环

通过真题语境、主动提取和间隔复习形成长期可调用词汇。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 背过多次仍认不出；阅读中认识但写不出；同一词反复错。 |
| 主方法 | 采用“原句识别—遮义回忆—词块输出—3/7/14 天回测”的闭环。 |
| 替代/验证路线 | 按词族、主题、同义改写或错误来源建立多入口索引。 |
| 复核标准 | 能在不同句子中识别并输出，而不仅能看到单词卡想起中文。 |
| 易错边界 | 不要无限抄词典；不要把低频生词和高频核心词投入同等时间。 |
| 典型任务 | 真题词表、写作词块、反复错词、熟词生义。 |
| 达标标准 | 核心词在三次跨语境回测中均能正确识别，重要词块能主动造句。 |

### 本节点七项检查

- [ ] 词汇按真题来源、主题和错误次数标记优先级。
- [ ] 每张词卡只保留与当前语境相关的必要信息。
- [ ] 完成当天、3 天、7 天、14 天主动提取。
- [ ] 能从中文功能或英文语境双向调用重要词块。
- [ ] 对反复错误词建立“混淆对象—最小差异”记录。
- [ ] 每周淘汰已稳定掌握的卡片，避免复习队列无限膨胀。
- [ ] 每月用新文章抽查词汇迁移，而非只复习旧卡。
