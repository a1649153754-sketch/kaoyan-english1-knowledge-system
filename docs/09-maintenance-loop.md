# 复习闭环与维护系统

## 9.1 每日最小闭环

1. **输入**：完成一小段真题或一个节点训练。
2. **证据**：标出原文证据、结构或写作任务要点。
3. **归因**：使用统一错误标签，不写“粗心”作为终点。
4. **修复**：写一条可迁移规则，制作一个新例或重写一句。
5. **回测**：安排 3/7/14 天主动提取。

## 9.2 节点升级规则

- 0→1：能说清节点研究什么。
- 1→2：有提示可完成常规题。
- 2→3：不同年份真题中稳定正确且用时达标。
- 3→4：能解释错项、边界，并迁移到翻译或写作输出。

## 9.3 A+/A/B/C 优先级

| 优先级 | 含义 | 周训练策略 |
| --- | --- | --- |
| A+ | 高分值或当前明显短板 | 每周至少 3 次，必须回测 |
| A | 高频核心能力 | 每周至少 2 次 |
| B | 性价比中等或基础维护 | 每周 1 次或随真题复盘 |
| C | 低频、已稳定或暂缓内容 | 月度抽查 |

## 9.4 3/7/14 天回测

- **3 天**：遮住解析，重做原题并口述证据。
- **7 天**：做同母题的新题或改写例句。
- **14 天**：放入整篇/整卷中检查迁移和用时。

## 9.5 每周复盘问题

- 本周最高频的三个错误标签是什么？
- 哪个节点“会讲但做不对”，说明掌握证据不足？
- 哪个题型用时波动最大？
- 哪条词汇/句法规则已迁移到写作或翻译？
- 下周唯一最重要的修复目标是什么？
