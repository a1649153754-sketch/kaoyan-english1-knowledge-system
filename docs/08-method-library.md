# M · 跨模块方法与复盘

> 把词汇、句法、证据、时间和错题数据连接成可持续迭代的备考系统。

默认优先级：**A+**。优先级会随个人真题数据调整。

## M1 整卷时间与分数策略

根据个人强弱项建立可执行的整卷顺序、时间预算和止损规则。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 某一篇阅读或翻译耗时过长；作文留时不足；做题顺序频繁变化。 |
| 主方法 | 先用模考数据确定模块预算，再设单题止损点和最后复核时间。 |
| 替代/验证路线 | 比较两种顺序的得分率与波动，选择更稳定者。 |
| 复核标准 | 总时间闭合，强项不因赶时间失分，弱项有最低保障。 |
| 易错边界 | 他人的顺序不必照搬；一次高分不能证明策略稳定。 |
| 典型任务 | 整卷顺序、时间预算、难题跳过、复核。 |
| 达标标准 | 连续三套在相近时间内完成，模块用时波动可控。 |

### 本节点七项检查

- [ ] 有明确的整卷模块顺序。
- [ ] 为每个模块设置目标用时和上限。
- [ ] 有单题卡住时的跳过规则。
- [ ] 至少保留一次整卷检查时间。
- [ ] 记录每套卷各模块用时和得分。
- [ ] 用三套以上数据评估策略。
- [ ] 策略调整后能说明预期收益与风险。

## M2 证据链与选项审判

统一阅读、完形和新题型的“原文证据—改写—结论”判断方式。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 两个选项都像对；凭感觉选择；错后只看答案解析。 |
| 主方法 | 为候选项写出主体、动作、条件、范围和态度，并逐一对照原文。 |
| 替代/验证路线 | 优先寻找反证：原文哪一点使该选项不能成立。 |
| 复核标准 | 正确项有正向证据，错误项能指出具体偷换类型。 |
| 易错边界 | 常识、立场偏好和“似乎合理”都不能替代文本证据。 |
| 典型任务 | 所有客观题的证据复盘。 |
| 达标标准 | 每道错题能写出最小证据区间与错项机制。 |

### 本节点七项检查

- [ ] 能把选项拆成可核对的命题要素。
- [ ] 能找到最小原文证据区间。
- [ ] 能识别主体、范围、因果、时间和态度偷换。
- [ ] 能区分正向证明与排除。
- [ ] 能记录正确项的同义改写。
- [ ] 能给错项贴统一错误标签。
- [ ] 复测时先独立重做再看旧解析。

## M3 真题精读与句词回收

从一篇真题中回收结构、词汇、句法、选项改写和写作表达。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 做完只对答案；抄大量生词但没有迁移；精读耗时无限。 |
| 主方法 | 按“题目证据—段落骨架—长句—核心词块—可迁移表达”五层回收。 |
| 替代/验证路线 | 限制每篇必须回收的项目数量，优先高频和反复错点。 |
| 复核标准 | 复盘产出可检索、可回测，且能改善下一篇表现。 |
| 易错边界 | 精读不是逐词查词典；不是把整篇翻译一遍就结束。 |
| 典型任务 | 真题复盘、词汇回收、长句分析、写作迁移。 |
| 达标标准 | 一篇精读能形成 1 张段落图、3—8 个词块、1—3 个长句和错题记录。 |

### 本节点七项检查

- [ ] 先复盘题目证据和错项机制。
- [ ] 能画出文章段落功能图。
- [ ] 只拆解真正影响理解的长句。
- [ ] 只回收高频或可迁移词块。
- [ ] 能提取一两个可用于写作的表达。
- [ ] 复盘时长有上限。
- [ ] 3/7/14 天完成回测。

## M4 错误标签与迁移修复

把“这题错了”转化为可统计的能力缺口和具体修复动作。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 同类错误反复出现；错题本只有答案，没有原因和复测。 |
| 主方法 | 使用 LEX/SYN/LOG/EVI/INF/TIME/EXP/FMT 标签，写一句根因和一个迁移规则。 |
| 替代/验证路线 | 将错题改造成一个新例句或同型小题，检验是否真正修复。 |
| 复核标准 | 错误标签稳定，修复动作具体，复测能避免同类错。 |
| 易错边界 | 不要把所有错误归为“粗心”；结果标签不能替代根因。 |
| 典型任务 | 错题库、数据统计、复测、学习优先级。 |
| 达标标准 | 能每周输出前三类失分原因和下一周唯一主修复目标。 |

### 本节点七项检查

- [ ] 会使用统一的八类错误标签。
- [ ] 每道错题写出一句根因。
- [ ] 每道错题写出一个可迁移规则。
- [ ] 能区分知识缺口、方法错误和时间失控。
- [ ] 能把错题改造成新例验证迁移。
- [ ] 按 3/7/14 天安排复测。
- [ ] 每周按标签统计失分而非只看总分。

## M5 阶段计划与掌握证据

用可观察证据而非主观感觉判断知识点是否掌握。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 觉得“学过了”但真题不会；复习计划只写章节，不写验收。 |
| 主方法 | 给节点设置 0—4 级，升级必须有正确率、用时、口述或输出证据。 |
| 替代/验证路线 | 用不同年份、不同文章和不同任务验证迁移。 |
| 复核标准 | 等级与真实表现一致，复习资源向 A+/A 薄弱节点集中。 |
| 易错边界 | 完成课程或抄完笔记不等于掌握；单次正确不等于稳定。 |
| 典型任务 | 阶段计划、优先级、节点升级、模考复盘。 |
| 达标标准 | 每周能更新节点等级，并说明每次升级或降级的证据。 |

### 本节点七项检查

- [ ] 理解 0—4 级掌握标准。
- [ ] 为节点设置 A+/A/B/C 优先级。
- [ ] 升级时记录题号、正确率和用时。
- [ ] 能用口述或重写证明主动调用。
- [ ] 能在新材料中验证迁移。
- [ ] 失误后会降级并安排修复。
- [ ] 每周只保留 3—5 个主攻节点。
