# W · 写作

> 以任务完成和低错误率为底座，建立小作文功能库、图画作文论证链和可迭代表达库。

默认优先级：**A+**。优先级会随个人真题数据调整。

## 模块节点总览

| 节点 | 主题 | 学习目标 | 达标证据 |
| --- | --- | --- | --- |
| W1 | 小作文任务审题与格式 | 准确识别身份、对象、目的、必写要点、语气和格式。 | 能在 1 分钟内列出任务清单，并在成稿中逐项勾销。 |
| W2 | 小作文功能句与内容展开 | 用稳定、自然的功能句完成邀请、建议、道歉、感谢、推荐、询问和通知。 | 能对同一功能写出两种不同但准确的表达。 |
| W3 | 大作文图画描述与寓意提炼 | 准确描述图画主体、动作、对比和文字信息，并提炼可论证的中心寓意。 | 能在 2 分钟内写出 3 句描述和 1 句中心寓意。 |
| W4 | 论证段落、逻辑链与例证 | 围绕中心观点展开原因、影响、例证和建议，形成层次清楚的主体段。 | 能写出两段不同角度的论证，每段 4—5 句且逻辑闭合。 |
| W5 | 语言准确性、升级与批改闭环 | 建立低错误率句型库，并通过自改和重写提高表达多样性。 | 同一篇作文在批改后能完成二稿，错误不重复，表达更自然。 |

## W1 小作文任务审题与格式

准确识别身份、对象、目的、必写要点、语气和格式。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目要求写信、通知、建议、邀请、道歉、推荐等；内容要点容易漏。 |
| 主方法 | 在草稿区写六项：身份、收件人、目的、要点、语气、落款，再组织段落。 |
| 替代/验证路线 | 完成后逐项对照题干，确认每个任务动作都有对应句。 |
| 复核标准 | 格式正确、要点齐全、语气合适、无无关展开。 |
| 易错边界 | 不要用万能开头掩盖任务；正式与非正式语气不可混用。 |
| 典型任务 | 书信、邮件、通知、备忘、告示等应用文。 |
| 达标标准 | 能在 1 分钟内列出任务清单，并在成稿中逐项勾销。 |

### 本节点七项检查

- [ ] 能识别写作身份和收件对象。
- [ ] 能提取全部显性与隐性任务要点。
- [ ] 能选择正式、半正式或友好语气。
- [ ] 掌握常见称呼、正文和落款格式。
- [ ] 能按目的组织 2—3 个短段落。
- [ ] 不会加入与任务无关的大段议论。
- [ ] 成稿后能逐项核对任务完成度。

## W2 小作文功能句与内容展开

用稳定、自然的功能句完成邀请、建议、道歉、感谢、推荐、询问和通知。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 知道要写什么但句子重复；表达过于生硬或空泛。 |
| 主方法 | 按“目的句—具体信息—行动请求/期待”构建，每个要点配一个具体细节。 |
| 替代/验证路线 | 把套话替换为与题目对象、时间、地点、原因相关的具体内容。 |
| 复核标准 | 功能明确、信息具体、语气礼貌，句型准确。 |
| 易错边界 | 功能句库不是整篇模板；不要堆砌高级表达导致语法错误。 |
| 典型任务 | 各种应用文功能段、结尾请求、礼貌表达。 |
| 达标标准 | 能对同一功能写出两种不同但准确的表达。 |

### 本节点七项检查

- [ ] 掌握说明写信目的的简洁句型。
- [ ] 能给建议提供理由和可执行细节。
- [ ] 能写清邀请的时间、地点、活动和回复方式。
- [ ] 能在道歉中说明原因、补救和责任态度。
- [ ] 能在推荐中写对象、优势和适配理由。
- [ ] 能使用礼貌请求而不过度谦卑。
- [ ] 能避免同一句式连续重复。

## W3 大作文图画描述与寓意提炼

准确描述图画主体、动作、对比和文字信息，并提炼可论证的中心寓意。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 图中元素多；只会罗列细节；寓意过大或偏题。 |
| 主方法 | 先写主体—动作—环境—对比—文字，再问图画赞扬/批评什么行为与价值。 |
| 替代/验证路线 | 用一句“图画不只是……更是在……”检验描述与寓意是否连接。 |
| 复核标准 | 描述客观准确，寓意由图中关系推出，主题范围适中。 |
| 易错边界 | 不要臆造图外故事；不要把具体行为无限上升到空泛宏大主题。 |
| 典型任务 | 图画描述、标题/文字解释、寓意句、首段组织。 |
| 达标标准 | 能在 2 分钟内写出 3 句描述和 1 句中心寓意。 |

### 本节点七项检查

- [ ] 能确定图画的核心主体和关键动作。
- [ ] 能描述位置、数量、表情和对比关系。
- [ ] 能自然引入图中文字或标题。
- [ ] 能区分客观描述与主观解读。
- [ ] 能从行为关系提炼价值主题。
- [ ] 寓意范围不过宽也不过窄。
- [ ] 首段能顺畅过渡到中心观点。

## W4 论证段落、逻辑链与例证

围绕中心观点展开原因、影响、例证和建议，形成层次清楚的主体段。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 段落只有口号；例子与观点脱节；连接词堆砌。 |
| 主方法 | 每段使用“主题句—解释机制—例证/后果—小结”四步链。 |
| 替代/验证路线 | 删掉连接词后检查逻辑是否仍成立；例子必须明确服务哪一条观点。 |
| 复核标准 | 每段只有一个中心，论证有因果机制，例子具体且相关。 |
| 易错边界 | 不要用名人名言代替论证；不要编造精确数据；不要每句都用连接词。 |
| 典型任务 | 原因分析、影响、个人社会例证、建议与结论。 |
| 达标标准 | 能写出两段不同角度的论证，每段 4—5 句且逻辑闭合。 |

### 本节点七项检查

- [ ] 能为每段写一个明确主题句。
- [ ] 能解释观点为何成立，而不是重复观点。
- [ ] 能使用个人、社会或制度层面的例证。
- [ ] 能让例证回扣主题句。
- [ ] 能区分原因、结果、对比和让步。
- [ ] 能使用适量连接手段而非机械堆砌。
- [ ] 结尾能总结并给出适度建议。

## W5 语言准确性、升级与批改闭环

建立低错误率句型库，并通过自改和重写提高表达多样性。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 词汇看似高级但搭配错；主谓、时态、冠词、单复数反复失分。 |
| 主方法 | 先保证简单句准确，再用从句、非谓语、同义替换和句式变化做有限升级。 |
| 替代/验证路线 | 完成后按动词、名词、修饰、连接、拼写五遍快速扫描。 |
| 复核标准 | 关键句准确，词块自然，句式有变化但不冒险。 |
| 易错边界 | 高级不等于复杂；背诵模板不能替代题目适配；同义词不可随意替换。 |
| 典型任务 | 语法纠错、词块升级、句式变化、重写与评分。 |
| 达标标准 | 同一篇作文在批改后能完成二稿，错误不重复，表达更自然。 |

### 本节点七项检查

- [ ] 能检查主谓一致、时态、语态和非谓语。
- [ ] 能检查冠词、单复数、代词和介词。
- [ ] 能检查搭配与词性。
- [ ] 能用长短句、从句和非谓语适度变化。
- [ ] 能用准确同义表达减少重复。
- [ ] 每篇作文都完成错误标签和二稿重写。
- [ ] 建立个人高正确率句型库并定期淘汰生硬模板。
