# 高频任务决策树（12 条）

> 决策树解决“看到题后第一步做什么”，不是替代完整分析。

## D-01 生词/熟词生义

**1. 先判词性与句法角色** → **2. 看左右搭配和对象限制** → **3. 看段落主题与褒贬方向** → **4. 比较候选义代回后的信息损失** → **5. 记录语境义与词块**

## D-02 长难句

**1. 圈标点和连词** → **2. 找主句谓语与主干** → **3. 标从句边界和非谓语逻辑主语** → **4. 处理指代与逻辑关系** → **5. 按汉语顺序重组并回文验证**

## D-03 完形单空

**1. 先判断语义/逻辑/搭配/语法主导类型** → **2. 提取本句限制** → **3. 调用段落主题与后文信息** → **4. 比较两个候选的证据数量** → **5. 无新增证据不改首选**

## D-04 阅读细节题

**1. 拆题干主体、动作、对象、条件** → **2. 用稳定定位词回文** → **3. 阅读证据句及前后一句** → **4. 逐项核对范围、因果、态度** → **5. 标最小证据区间**

## D-05 阅读推断题

**1. 先找明确证据** → **2. 写出证据允许的最小结论** → **3. 检查是否跨越超过一层逻辑** → **4. 排除绝对化和常识补充** → **5. 用限制词校准强度**

## D-06 阅读态度题

**1. 确定态度主体与对象** → **2. 抓评价词和转折后信息** → **3. 区分事实引用与作者评价** → **4. 校准正负与强度** → **5. 排除情绪过强选项**

## D-07 主旨/标题题

**1. 标各段功能** → **2. 找重复概念和中心争议** → **3. 先自行概括** → **4. 检查候选能否覆盖每段** → **5. 排除过宽、过窄和局部细节**

## D-08 七选五

**1. 判断空格功能** → **2. 找代词、连接词、复现和平行** → **3. 同时检查空前与空后** → **4. 先锁强连接** → **5. 全文通读检查主题连续**

## D-09 段落排序

**1. 找无前指起点** → **2. 锁定强指代/问答/时间配对** → **3. 连接概念引入与展开** → **4. 确定总结终点** → **5. 用全文逻辑复核**

## D-10 翻译划线句

**1. 切块并找主干** → **2. 确定修饰附着与指代** → **3. 逐块确定词义和逻辑** → **4. 按汉语重组** → **5. 检查信息、否定、比较与流畅度**

## D-11 小作文

**1. 圈身份、对象、目的、要点、语气、格式** → **2. 列 2—3 段功能** → **3. 每个要点补一个具体信息** → **4. 使用高正确率功能句** → **5. 核对任务清单与格式**

## D-12 图画大作文

**1. 客观描述主体与对比** → **2. 提炼适度寓意** → **3. 列两个论证角度** → **4. 每段写机制与例证** → **5. 五遍扫描并安排二稿**
