# T · 英译汉

> 以结构准确为底线，以信息完整和自然汉语为目标，逐层拆解并重组划线句。

默认优先级：**A+**。优先级会随个人真题数据调整。

## 模块节点总览

| 节点 | 主题 | 学习目标 | 达标证据 |
| --- | --- | --- | --- |
| T1 | 切分、主干与评分信息点 | 先确定句子骨架和主要信息点，再处理修饰成分。 | 能在落笔前用 20 秒写出结构分块和主干译文。 |
| T2 | 从句、非谓语与修饰关系 | 把英语后置、嵌套和压缩修饰转化为清楚的汉语层次。 | 能对同一句给出至少两种重组方案并选择更自然者。 |
| T3 | 词义选择、抽象名词与代词 | 在语境中选择自然词义，处理名词化、抽象表达和指代。 | 能解释关键实词为何取该义，并把抽象名词转成自然汉语。 |
| T4 | 语序重组、被动与否定比较 | 按汉语信息顺序重组原句，准确表达被动、否定、比较、让步和因果。 | 能在不损失信息的前提下摆脱英文线性语序。 |
| T5 | 成稿、复核与评分稳定性 | 在结构准确基础上形成完整、通顺、不过度发挥的中文译文。 | 连续五句在限时内做到主干正确、信息完整、汉语可读。 |

## T1 切分、主干与评分信息点

先确定句子骨架和主要信息点，再处理修饰成分。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 划线句长、从句多、逐词翻译失控。 |
| 主方法 | 按谓语、连词、标点切块，找主句主干，标出每个不可丢失的信息点。 |
| 替代/验证路线 | 把主干单独译出，再逐块附加，检查信息是否完整。 |
| 复核标准 | 主干关系正确，所有关键成分都有落点，中文逻辑清楚。 |
| 易错边界 | 不要一上来从第一个词顺译到最后；不要为流畅而删掉限定条件。 |
| 典型任务 | 长句主干、嵌套从句、评分点分解。 |
| 达标标准 | 能在落笔前用 20 秒写出结构分块和主干译文。 |

### 本节点七项检查

- [ ] 能找出主句谓语和主语。
- [ ] 能按连词和标点划分从句与意群。
- [ ] 能标出不可遗漏的否定、比较、条件和范围。
- [ ] 能先译主干再处理修饰。
- [ ] 能为每个分块确定中文落点。
- [ ] 能检查信息是否重复或遗漏。
- [ ] 能用结构标注解释译文依据。

## T2 从句、非谓语与修饰关系

把英语后置、嵌套和压缩修饰转化为清楚的汉语层次。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 多层定语从句、非谓语、同位语、插入语。 |
| 主方法 | 先确定修饰对象和逻辑关系，再决定前置、后置或拆成独立分句。 |
| 替代/验证路线 | 将非谓语展开为从句，比较哪种汉语结构更自然。 |
| 复核标准 | 修饰对象不串位，层级清楚，长定语不过度堆叠。 |
| 易错边界 | 英语定语不能一律前置；逗号从句不一定都译成“这”。 |
| 典型任务 | 定语从句、同位语、非谓语、插入语翻译。 |
| 达标标准 | 能对同一句给出至少两种重组方案并选择更自然者。 |

### 本节点七项检查

- [ ] 能识别每个从句的功能和先行对象。
- [ ] 能判断限制性与补充性信息。
- [ ] 能把非谓语还原为主动或被动关系。
- [ ] 能处理同位解释和插入评论。
- [ ] 能决定长定语前置、后置或拆句。
- [ ] 能避免修饰对象错位。
- [ ] 能用汉语标点重新组织层次。

## T3 词义选择、抽象名词与代词

在语境中选择自然词义，处理名词化、抽象表达和指代。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 熟词生义、抽象名词连串、it/this/that/they 回指不清。 |
| 主方法 | 先确定词性与搭配，再将抽象名词还原为动作、性质或关系，明确指代对象。 |
| 替代/验证路线 | 用上下文替换测试确认词义，并检查汉语是否需要增补主语或动词。 |
| 复核标准 | 词义准确、指代清楚、抽象表达转化自然。 |
| 易错边界 | 不要把所有名词都硬译成“……性/……化”；不要机械译每个代词。 |
| 典型任务 | 熟词生义、名词化、代词、术语与普通义。 |
| 达标标准 | 能解释关键实词为何取该义，并把抽象名词转成自然汉语。 |

### 本节点七项检查

- [ ] 能根据搭配和论证方向确定实词语境义。
- [ ] 能将动作性名词还原为动词表达。
- [ ] 能将性质性名词转化为形容或判断。
- [ ] 能明确代词和指示词的回指对象。
- [ ] 能区分术语义与普通语境义。
- [ ] 能避免中文空泛词堆叠。
- [ ] 复盘时记录最关键的词义选择证据。

## T4 语序重组、被动与否定比较

按汉语信息顺序重组原句，准确表达被动、否定、比较、让步和因果。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 英文语序直译生硬；被动句无自然主语；否定范围或比较对象易错。 |
| 主方法 | 先写逻辑关系，再选择主动、无主句或被动表达，最后调整时间与因果顺序。 |
| 替代/验证路线 | 把译文回译为逻辑命题，检查否定和比较是否保真。 |
| 复核标准 | 逻辑关系、范围和比较对象准确，汉语顺序自然。 |
| 易错边界 | 被动不必都有“被”；否定词位置改变可能改变命题；比较对象必须同类。 |
| 典型任务 | 被动、否定、比较、让步、因果的汉语化。 |
| 达标标准 | 能在不损失信息的前提下摆脱英文线性语序。 |

### 本节点七项检查

- [ ] 能判断被动是否改为主动或无主句。
- [ ] 能确定否定词作用范围。
- [ ] 能补全省略的比较对象。
- [ ] 能调整原因、结果、条件和让步的顺序。
- [ ] 能处理形式主语和形式宾语。
- [ ] 能避免中文主语频繁跳换。
- [ ] 能回查逻辑命题是否与原文一致。

## T5 成稿、复核与评分稳定性

在结构准确基础上形成完整、通顺、不过度发挥的中文译文。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 结构分析正确但成稿生硬；漏译小词；改写过度。 |
| 主方法 | 按“结构—信息—逻辑—词义—汉语—书写”六层复核。 |
| 替代/验证路线 | 让另一版更直白的译文与成稿对照，检查是否因润色丢信息。 |
| 复核标准 | 译文准确、完整、通顺，关键限定和逻辑标志保留。 |
| 易错边界 | 不追求文学化；不添加作者未表达的评价；不要在一个词上耗时过多。 |
| 典型任务 | 译文润色、漏译检查、限时训练、评分复盘。 |
| 达标标准 | 连续五句在限时内做到主干正确、信息完整、汉语可读。 |

### 本节点七项检查

- [ ] 完成后核对主干关系。
- [ ] 逐块检查有无漏译和重复。
- [ ] 检查否定、比较、时间和逻辑词。
- [ ] 检查代词与主语是否清楚。
- [ ] 删除生硬的英文式长定语。
- [ ] 控制润色，不增添原文没有的信息。
- [ ] 记录每句失分属于结构、词义还是表达。
