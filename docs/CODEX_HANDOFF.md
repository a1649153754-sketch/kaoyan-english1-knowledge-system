## 不可破坏的边界

1. `V/G/C/R/N/T/W/M` 节点和 `K/Q/B/J/D` 资源 ID 不得随意重编号。
2. 客观题不能只记录答案，必须说明最小证据和错项为何错。
3. 翻译与写作不能只追求“高级表达”，必须优先保证任务完成、逻辑闭合和搭配准确。
4. 不复制真题文章、完整题面、答案全文、教材或付费课程大段内容。
5. 个人正确率、用时、错题正文和复测日期在建立私有层后只能保存在本地覆盖层。
