# R · 阅读理解 A

> 以原文证据链为核心，系统处理细节、推断、态度、词义、主旨和结构题。

默认优先级：**A**。优先级会随个人真题数据调整。

## 模块节点总览

| 节点 | 主题 | 学习目标 | 达标证据 |
| --- | --- | --- | --- |
| R1 | 篇章结构与段落功能 | 识别文章中心问题、段落功能、观点关系和论证推进。 | 能在 60 秒内口述“问题—分歧—证据—结论”的文章骨架。 |

## R1 篇章结构与段落功能

识别文章中心问题、段落功能、观点关系和论证推进。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 文章信息很多但主线不清；段落看懂却不知道为何出现。 |
| 主方法 | 读完每段用功能标签概括：提出问题、解释、例证、转折、反驳、结论。 |
| 替代/验证路线 | 用首尾句、转折后和重复概念构建一条文章骨架。 |
| 复核标准 | 各段功能能串成连续论证，中心问题和作者立场清楚。 |
| 易错边界 | 段落首句不总是主题句；例子内容不等于段落主旨。 |
| 典型任务 | 主旨题、标题题、段落作用、结构题、快速回文。 |
| 达标标准 | 能在 60 秒内口述“问题—分歧—证据—结论”的文章骨架。 |

### 本节点七项检查

- [ ] 能为每段标注一个功能标签。
- [ ] 能识别转折、让步和结论后的高权重信息。
- [ ] 能区分作者观点、他人观点和背景事实。
- [ ] 能识别例子服务的上位观点。
- [ ] 能找出贯穿全文的重复概念及同义改写。
- [ ] 能画出段落间因果、对比或递进关系。
- [ ] 能用一句话概括全文中心问题与作者答案。

## R2 细节定位与同义改写

用题干定位词找到证据句，并识别选项对原文的同义改写或偷换。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题干问具体事实、原因、方式、对象；正确选项很少原词复现。 |
| 主方法 | 提取专名、数字、动作和逻辑关系定位；读证据句及前后一句；比较命题单位。 |
| 替代/验证路线 | 把每个选项反向改写成原文命题，逐项检查对象、范围和因果。 |
| 复核标准 | 正确项与原文在主体、动作、条件、范围和态度上等值。 |
| 易错边界 | 不要只做关键词匹配；原文词复现可能是干扰项诱饵。 |
| 典型任务 | 事实细节、原因细节、指代细节、同义替换。 |
| 达标标准 | 能给每道细节题标出最小证据区间，并解释三个错项的偷换点。 |

### 本节点七项检查

- [ ] 能从题干提取稳定定位词。
- [ ] 能识别题干和原文之间的同义改写。
- [ ] 能把证据区间控制在必要的 1—3 句。
- [ ] 能核对主体、动作、对象、时间和条件。
- [ ] 能识别范围扩大、对象替换和因果倒置。
- [ ] 不会因为选项复现原词就直接选择。
- [ ] 复盘时能记录正确项的改写方式。

## R3 推断、态度与观点边界

从明确证据作最小必要推断，并判断作者或特定人物的态度。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题干出现 infer/imply/suggest/attitude/tone；原文没有答案原句。 |
| 主方法 | 先定位证据，再问“原文至少保证什么”；态度题抓评价词、转折和结论。 |
| 替代/验证路线 | 尝试寻找能直接反驳选项的原文限制条件，优先排除过强推断。 |
| 复核标准 | 推断不超出证据，态度对象明确，语气强度与原文一致。 |
| 易错边界 | 合理常识不等于原文推断；作者引用他人观点不代表赞同。 |
| 典型任务 | 推断题、态度题、观点判断、语气强弱。 |
| 达标标准 | 能写出“证据—桥梁—结论”三步链，桥梁不超过一层。 |

### 本节点七项检查

- [ ] 能区分事实复述、合理推断和无依据想象。
- [ ] 能把推断限制在一层逻辑内。
- [ ] 能识别作者与被引述者的观点边界。
- [ ] 能利用评价形容词、副词和动词判断态度。
- [ ] 能区分谨慎、怀疑、批评、支持等强度。
- [ ] 能排除绝对化和情绪过强的选项。
- [ ] 能用原文限制词校准推断范围。

## R4 词义、指代、例证与句意

处理词句在具体语境中的意义，以及代词、例子和引用的论证功能。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题干问某词/短语/句子含义，或 why does the author mention...。 |
| 主方法 | 先看所在句的结构，再看前后逻辑；例证题向上寻找其支持或反驳的观点。 |
| 替代/验证路线 | 用自拟的简短释义替换原词句，检查是否保持段落方向。 |
| 复核标准 | 释义符合上下文，指代对象在数与语义上匹配，例子功能指向上位观点。 |
| 易错边界 | 不要选词典最熟义；不要把例子本身当作作者最终观点。 |
| 典型任务 | 语境词义、指代、例证作用、长句含义。 |
| 达标标准 | 能用不超过 15 个中文词概括目标词句的语境功能。 |

### 本节点七项检查

- [ ] 能根据句法位置判断目标词词性和作用。
- [ ] 能利用同义、反义、因果和例证线索猜义。
- [ ] 能确定代词的语法和语义回指。
- [ ] 能区分例子的内容与例子的论证目的。
- [ ] 能把复杂句改写成简单命题。
- [ ] 能排除只符合词典义但不符合段落的选项。
- [ ] 复盘时记录目标词句与上位观点的关系。

## R5 主旨、标题与整篇复核

选择覆盖全文、对象准确、范围适中的主旨或标题，并建立稳定作答节奏。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 选项都提到文中内容；一个太宽、一个太窄、一个只写例子、一个接近主线。 |
| 主方法 | 综合首尾段、各段功能和重复概念，先自行概括，再匹配选项。 |
| 替代/验证路线 | 检验候选标题能否解释每一段为何存在，并排除只覆盖局部的选项。 |
| 复核标准 | 主题对象、核心争议和作者倾向均覆盖，范围不过宽也不过窄。 |
| 易错边界 | 生动不等于准确；标题不必包含所有细节，但必须覆盖中心问题。 |
| 典型任务 | 全文主旨、最佳标题、文章目的、时间管理。 |
| 达标标准 | 能在不看选项时先写出 20 字以内主旨，再稳定匹配答案。 |

### 本节点七项检查

- [ ] 能区分主题、中心观点和写作目的。
- [ ] 能用各段功能验证主旨覆盖范围。
- [ ] 能排除只概括某一段或某一例子的选项。
- [ ] 能排除范围过宽、态度过强或对象错误的标题。
- [ ] 能在看选项前形成自己的主旨表达。
- [ ] 有稳定的每篇阅读用时和题目顺序。
- [ ] 做完能回看高风险题而不重新通读全文。
