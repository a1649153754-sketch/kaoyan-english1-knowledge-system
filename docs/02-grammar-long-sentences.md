# G · 语法与长难句

> 把语法从规则记忆转化为主干定位、修饰边界、逻辑关系和翻译重组能力。

默认优先级：**A+**。优先级会随个人真题数据调整。

## G1 基本句型与主干定位

识别句子的核心谓语、主语、宾语或表语，建立所有长难句分析的骨架。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 句子很长、逗号很多、多个动词并存，不确定哪个是谓语。 |
| 主方法 | 先圈连词与标点，再找有时态的人称动词，排除非谓语，确定主句主干。 |
| 替代/验证路线 | 从句尾回看谓语所支配的主语和宾语，验证主谓一致与语义完整。 |
| 复核标准 | 主干能独立成句，谓语数量与连词数量大致匹配，修饰成分可暂时删除。 |
| 易错边界 | 看到动词形式不等于看到谓语；过去分词和现在分词常作修饰或补语。 |
| 典型任务 | 长难句主干、翻译切分、阅读句意题、写作病句。 |
| 达标标准 | 能在 15 秒内标出主句 S-V-O/C，并说明其余成分附着位置。 |

### 本节点七项检查

- [ ] 能识别五种基本句型及常见扩展。
- [ ] 能区分谓语动词、非谓语动词和从句谓语。
- [ ] 能利用时态、人称和连词判断谓语层级。
- [ ] 能暂时删除介词短语、同位语和插入语保留主干。
- [ ] 能判断宾语、表语、宾补和双宾语。
- [ ] 能用主谓一致反查主语边界。
- [ ] 长句分析后能还原为简短、语义完整的主干句。

## G2 三大从句与关系词

判断名词性、定语和状语从句的功能、边界及关系词在从句中的成分。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | that/which/when/where/what 等关系词难区分；从句嵌套；先行词不明显。 |
| 主方法 | 先问从句整体在主句中充当什么成分，再问关系词在从句内部是否缺成分。 |
| 替代/验证路线 | 将从句替换为名词、形容词或副词功能块，检查主句结构是否完整。 |
| 复核标准 | 从句功能、关系词成分和语义关系三者一致。 |
| 易错边界 | 不要只凭先行词是“时间/地点”就选 when/where；关键是从句内部缺什么。 |
| 典型任务 | 关系词选择、长句切分、翻译定语从句、写作从句。 |
| 达标标准 | 能解释 that 与 when/where/which 的选择依据，而非凭中文感觉。 |

### 本节点七项检查

- [ ] 能识别主语、宾语、表语和同位语从句。
- [ ] 能判断定语从句关系词在从句中作主语、宾语或状语。
- [ ] 能区分限制性与非限制性定语从句的作用。
- [ ] 能识别时间、原因、条件、让步、目的、结果、比较状语从句。
- [ ] 能处理介词前置的关系结构。
- [ ] 能判断 what 与 that 的结构差别。
- [ ] 能在嵌套从句中逐层标注起点、终点和附着对象。

## G3 非谓语与压缩结构

识别不定式、动名词、现在分词和过去分词的逻辑主语、时间和语态关系。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 句中多个 -ing/-ed/to do；不知道修饰谁；翻译时关系混乱。 |
| 主方法 | 先找非谓语的逻辑主语，再判断主动/被动与先后关系，最后确定句法功能。 |
| 替代/验证路线 | 将非谓语展开成从句，检查逻辑主语和时间关系是否合理。 |
| 复核标准 | 展开后的从句语义通顺，且与主句不存在悬垂修饰。 |
| 易错边界 | 形式相同功能可不同；-ed 不总表示过去，-ing 不总表示进行。 |
| 典型任务 | 非谓语作定语、状语、补语，独立主格，翻译切分。 |
| 达标标准 | 能把常见非谓语结构双向改写为从句，并保持逻辑关系。 |

### 本节点七项检查

- [ ] 能区分不定式、动名词和分词的核心功能。
- [ ] 能确定非谓语的逻辑主语。
- [ ] 能判断主动、被动、完成和进行关系。
- [ ] 能识别非谓语作定语、状语、宾补和主宾表语。
- [ ] 能识别独立主格和 with 复合结构。
- [ ] 能发现悬垂分词与逻辑主语不一致。
- [ ] 翻译时能把压缩结构展开为自然汉语分句。

## G4 特殊结构：倒装、强调、省略与比较

识别因语序变化或成分省略造成的表面陌生结构，恢复正常语序和完整信息。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 否定词前置、only 前置、it is/was、than/as 后省略、长比较结构。 |
| 主方法 | 先识别结构触发词，恢复正常语序或补全省略，再解释其强调焦点。 |
| 替代/验证路线 | 用普通陈述句改写，检查信息是否等价。 |
| 复核标准 | 改写后主干、否定范围、比较对象和强调焦点清楚。 |
| 易错边界 | 不要见 it is 就判强调；不要忽略否定前移导致的倒装；比较对象必须同类。 |
| 典型任务 | 阅读句意、翻译、完形语法、写作句式。 |
| 达标标准 | 能在不依赖术语的情况下把特殊结构还原并准确解释。 |

### 本节点七项检查

- [ ] 能识别完全倒装与部分倒装。
- [ ] 能识别否定、only、so/such 等触发的倒装。
- [ ] 能检验强调句去掉框架后是否仍为完整句。
- [ ] 能补全并列、比较和从句中的省略成分。
- [ ] 能处理 more/less than、no more than 等比较表达。
- [ ] 能确定否定词的作用范围。
- [ ] 能把特殊语序还原为自然逻辑顺序。

## G5 长难句综合切分与指代

整合主干、从句、非谓语、插入语和指代，形成可复核的句义。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 一句超过两行；多层嵌套；代词、this/that/such 指向不清。 |
| 主方法 | 按“标点/连词切块—主干—修饰附着—指代—逻辑—重组”六步处理。 |
| 替代/验证路线 | 先逐块释义，再用段落主题验证整体论证方向。 |
| 复核标准 | 每个修饰块有明确附着对象，每个代词有可回指内容，句义与段落一致。 |
| 易错边界 | 不要逐词顺译；不要让最近名词原则取代语义和数的一致检查。 |
| 典型任务 | 阅读关键句、翻译划线句、七选五衔接、完形篇章。 |
| 达标标准 | 能画出句子层级并在 60 秒内给出准确、自然的中文释义。 |

### 本节点七项检查

- [ ] 能用标点、并列连词和从属连词切分层级。
- [ ] 能标出主句与各从句的嵌套关系。
- [ ] 能判断介词短语、同位语和插入语的附着对象。
- [ ] 能解析代词、指示词和替代词的回指范围。
- [ ] 能识别句内因果、转折、让步和比较关系。
- [ ] 能先结构后翻译，避免逐词线性处理。
- [ ] 能用原文前后句验证最终句义。
